# WFC 网格场景编辑器：操作教程

版本 v0.3；UE 5.6；更新日期：2026-10-27。

这是 Unreal 编辑器内的网格规划工具。每格保存用途、建筑层数与可选模型，然后由生成器计算场景。当前附带街区/房屋模板；房间关卡的起点、首领、奖励、门连接图等专门语义尚未加入。

## 1. 打开工具和示例

1. 编译工程，打开 Unreal 编辑器。
2. 内容浏览器开启“显示插件内容”。
3. 打开 `/SpiritWFC/Settlement/Maps/L_WFC_GridEditorExample`。
4. 在世界大纲选中 **WFC Grid Editor Example - Select me**。
5. 顶部菜单 **工具（Tools）→ WFC 网格场景编辑器**。
6. 点击“读取选中生成器”。画板会读取地图大小、规划笔画和当前生成结果。

附带的可复用规划是 `/SpiritWFC/Settlement/Data/DA_WFC_PaintedExample`，样式规则是 `DA_WFC_Settlement`。不使用示例时，可在自己的关卡放置 `BP_WFC_Settlement_Planar` 或 `BP_WFC_Settlement_ThreeLayers`，再选中并读取。

## 2. 颜色表示什么

| 默认颜色 | 类型 | 计算时的含义 |
|---|---|---|
| 灰色 | 自动 / 橡皮 | 没有手工约束，由补齐设置决定是否放建筑 |
| 白色 | 道路 | 保留这个道路格子，按相邻道路计算直路、转角、岔路 |
| 绿色 | 建筑 | 固定建筑地块，可指定 1～3 层或选择完整房屋模型 |
| 黄色 | 广场 / 宽铺地 | 保留铺地区域，可以连成广场或较宽的铺装 |
| 红色 | 留空地面 | 生成地面，明确禁止自动补建筑 |

在笔刷按钮上**右键**可以修改显示颜色；颜色不直接改变世界材质，也不改变该类型的意义。颜色设置可跟随规划资产保存。

实色格子是手工约束，浅色格子显示当前自动生成结果。建筑上的数字是指定层数，`?` 表示随机层数，`M` 表示完整模型替换。

**擦成灰色与标红留空不同。** 灰格允许自动补齐，红格始终保留空地。本版的留空仍有地面；没有生成“虚空地牢背景”的专门模板。

## 3. 填格、框选和修改

- 左键按住拖动：连续填格。快速拖动也会补上中间格子；斜线会转换成上下左右相连的连续拐角。
- 右键按住拖动：擦除为灰色。
- 勾选“矩形填充”：从起点拖到终点，松开后填充矩形区域；右键拖动可矩形擦除。
- 勾选“选择/读取格子参数”：点击已标记格子，读取它的类型、层数、模型、缩放和朝向。关闭选择模式后再填回原格即可修改。
- “撤销 / 重做”：恢复画布笔画；撤销最多保留 32 个笔画快照。这不是三维场景生成历史的完整撤销系统。
- “清空”：清除本窗口的手工笔画；未点击计算时不会清理关卡里的旧生成结果。

画布向右为 +X，向上为 +Y。右侧可修改宽、高、立体模式、楼层数和种子；改变尺寸会剔除越界笔画并清除笔画历史。建议先保存规划副本再改变尺寸。

当前没有曲线道路网格挤出：曲线输入最终是格子拐角。需要平滑公路时，应后续增加曲线道路模块或样条道路生成层。

## 4. 三种计算方式

### 按草图补齐

先填道路、广场、建筑和保留空地，勾选“补齐灰格：自动选择临街建筑”，设置密度，再点 **计算：保留笔画并生成**。

系统保留涂色格子，在尚未标记且靠近道路的地块中选择建筑。不会改画道路，也不会擅自把两条分离道路连接起来。密度是对合格候选地块的概率，不是严格建筑数量。

### 严格按图

取消“补齐灰格”，再点击同一个计算按钮。只在绿色格放建筑，灰色和红色区域保留地面。手工道路和广场仍被保留。

### 完全自动

点击 **完全自动生成**，使用街区预设规划道路、广场和建筑。本窗口的笔画暂时保留，之后可再次点击按图计算。自动街区要求至少 9×9；手工规划至少 3×3。

无论哪种方式，都保留原始 Free WFC 入口。需要修改任意接口、权重和自由拼接时，仍可在生成器详情/自己的 TileSet 中配置；编辑面板主要服务带语义标签的街区规则。

## 5. 指定建筑楼层

使用规则库房屋时，选择建筑笔刷，设置层数，再填格：

- `0`：由种子选择 1～可用楼层数。
- `1 / 2 / 3`：固定层数。

平面模式只有一层，不能填三层建筑；需要先开启立体模式并设置可用楼层数。多层建筑使用 Base、Middle、Top 模块，楼梯列和朝向由规划保持一致。

建筑地块必须紧邻道路或广场，否则会报告不可达的地块坐标。先画道路，再放建筑最容易检查。手工道路可以有环路、分叉和断头路；是否适合作为玩法路线仍需进一步验收。

## 6. 替换某栋房子

1. 选择建筑笔刷。
2. 在“完整房屋模型”选择一个 **Static Mesh 静态网格**。
3. 工具会按当前地块宽度初步缩放并将模型包围盒底部对齐地面。
4. 按需要调整缩放、额外朝向和高度偏移。
5. 点击或框选需要替换的建筑格，再计算。

清空模型选择，就恢复使用规则库的房屋。替换前建议先用“选择/读取格子参数”读取已有格子；右侧调整只改变笔刷，重新填格并计算后才修改实际场景。

完整模型使用它自己的材质，并按“整栋积木”处理，占一个逻辑建筑格，不再叠加 Base/Middle/Top。它的内部楼层和门不会被自动识别。多层规则化建筑应通过整套样式资产配置。本版只支持静态网格，尚未支持任意 Actor 蓝图房屋或多格占位预制体。

地块自动适配只根据宽度，不保证门的净高或模型比例适合人物。模型正面默认按本地 -Y 面向街道；导入朝向不同可以调整额外朝向。检查模型碰撞、实际尺寸和高度后再投入玩法。

## 7. 更换整套建筑样式

复制 `DA_WFC_Settlement` 为自己的样式规则，替换对应 Tile 的模型、材质与权重，然后在画板的“整套建筑样式 / 规则资产”选择它。

保留规划器需要的标签：Ground、Road_00～Road_15、Plaza_00～Plaza_15、House、Base、Middle、Top、Air。Base/Middle/Top 的高度与楼梯开口必须配套。选择不具备这些标签的旧教学资产会提示缺少所需类型。

原始下载套件使用 300 cm 格子及 +90 cm 偏移；新街区套件使用 `(600,600,360)` cm 和单位变换。切换样式要同时核对它的 Cell Size 与模块 Pivot。保留在旧规则中的 Pinned Cells 也可能与新规则 ID 冲突，需要调整。

## 8. 保存、读取和复用

### 保存到关卡

点击计算后，规划数据写入选中生成器的 `Settings.PaintedCells`，可见实例与 Displayed Result 也保存在生成器上。按 Ctrl+S 保存关卡。

### 保存规划资产

点击 **保存规划资产**，在 UE 资源保存对话框中选择名称和位置。建议放到自己的 `/Game/ProceduralGeneration/WFC/Layouts`。该操作会创建一个新的 WFC Layout Asset，保存画布尺寸、笔画、种子、填充设置、模型引用、样式资产和配色。

每次保存通过资源对话框另建方案，适合保留版本。关卡保存与规划资产保存是两件事：只画图不计算、不保存规划，关闭窗口会丢失草稿；只保存规划也不会替你保存已经修改的关卡。

### 载入规划

在右侧选择规划资产，点“载入规划”。它会替换本窗口的画布和样式配置；再点击计算，把方案应用到读取过的生成器上。可以将同一规划用在自己的另一张关卡。

“导入当前布局”则把目前已经生成的地面、道路、广场、建筑转成手工约束，适合从一个自动结果继续修改。完整房屋替换信息也会保留。

## 9. 计算失败时

工具会显示失败原因，并保留上一次成功的三维结果。可定位的冲突格会以红边提示。常见情况：

| 问题 | 处理 |
|---|---|
| 建筑不临街 | 在相邻格补道路/广场，或移动建筑 |
| 填三层但可用楼层为一 | 开启立体模式或降低层数 |
| 找不到 Ground/Base 等标签 | 选择新街区规则或为自己的规则配齐标签 |
| 整栋替换与多层叠加冲突 | 整栋模型按一个逻辑格处理，分层建筑用样式库 |
| 输入或固定格冲突 | 核对 Pinned Cells、边界接口、尺寸和层数 |
| 计算后似乎没变化 | 检查是否失败；旧结果保留不代表新计算成功 |

全局硬上限仍为每轴最多64、总格数4096、最多三层、旋转变体256。生成是同步操作；大规模场景应先降低尺寸验证规则。

## 10. 程序接口与发布边界

- `FWFCPaintedCell`：坐标、类型、层数、完整房屋软引用及局部变换。
- `FWFCLayoutPlanner`：把手工输入或自动街区转为逐格语义约束。
- `FWFCPaintRaster` / `RasterizeRoadStroke`：把快速拖动栅格化为四连通笔画。
- `UWFCLayoutAsset`：可复用方案资产。
- `AWFCMapGenerator`：计算、资源加载、批量实例化、失败回退。
- `SpiritWFCEditor`：工具菜单和 Slate 画板，只在编辑器目标加载。

当前保留的是程序化布局与兼容模块选择，不是已经实现完整地牢关卡设计：起点/首领/奖励房间的数量、门图、主路径长度、关键节点距离等还需专门规则。楼梯碰撞、实际角色和 AI 导航也仍需在自己的场景中手动验收。

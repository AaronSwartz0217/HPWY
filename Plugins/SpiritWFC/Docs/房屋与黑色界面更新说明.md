# 房屋通行、复合街区与黑色界面

## 编辑器使用

打开 `/SpiritWFC/Settlement/Maps/L_WFC_CompoundHouses`，选中 WFC 生成器，点击 **Generate Map**。这是“二层主楼＋一层侧翼”的独立示例；侧翼前墙后退，形成 L 形轮廓，主副楼以侧门和有顶连接廊连通。

自动街区使用 `Settings.LayoutPreset = Settlement`。`MaxBuildingStories` 控制自动房屋最高层数，`CompoundBuildingChance` 为符合相邻条件的房屋尝试组合的概率，并非最终复合房屋占比。普通平面、立体示例分别为单层街区和最高二层街区，复合尝试概率均为 0.3；专门示例为 1.0。同一种子与配置可复现结果。

复合组合只占用已有相邻建筑格，不覆盖道路、广场，也不会重复占用另一组合的格子。立体主楼最高二层，侧翼一层；平面模式或层数上限为 1 时主副楼都为一层。上方剩余格保持 Air。

新设置的类默认值为最高三层、复合概率 0，兼容现有项目。Free 模式不使用街区分区；Painted 保持手绘布局，明确填写的建筑层数优先，自动复合不改动手绘格子。因此已保存的万象天宫不会自动新增侧翼；楼梯修复会在原布局上生效。若要生成新复合街区，请使用独立示例或自行选择 Settlement 模式。

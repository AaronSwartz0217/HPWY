# 开源参考、模型来源与许可证

## 算法参考

- [mxgmn/WaveFunctionCollapse](https://github.com/mxgmn/WaveFunctionCollapse)：WFC 的观察、加权熵与传播参考。代码采用 MIT，但仓库许可证**明确排除提供的样例/图块**，所以本项目没有把它的样例图片或模型当成 MIT 素材导入。见[其许可证](https://github.com/mxgmn/WaveFunctionCollapse/blob/master/LICENSE)。
- [marian42/wavefunctioncollapse](https://github.com/marian42/wavefunctioncollapse) 及[作者文章](https://marian42.de/article/wfc/)：模块建筑、连接面、旋转和回溯的设计参考。本插件是重新编写的 UE 实现，没有引入 Unity 代码、预制体、脚本或运行时依赖；本版选择有限重启，没有实现上游的回溯/无限地图。

## 实际转换与导入

Blender 3.6.4 后台导入原 FBX，检测到 151 个网格对象。本轮选择 12 个标准建筑模块，去除源场景展示排列、保留各自格子 Pivot，烘焙静态几何，输出独立 FBX。原素材不被覆盖；没有运行下载仓库的脚本。

| 源对象 | UE 静态网格 |
|---|---|
| Floor | SM_WFC_Floor |
| Wall | SM_WFC_Wall |
| Wall Corner 2 | SM_WFC_WallCorner |
| Wall Door | SM_WFC_Door |
| Wall Window | SM_WFC_Window |
| Interior Floor | SM_WFC_InteriorFloor |
| Water Fountain | SM_WFC_Fountain |
| Roof Single | SM_WFC_Roof |
| Stairs | SM_WFC_Stairs |
| Enclosed Stairs | SM_WFC_EnclosedStairs |
| Enclosed Stairs Lower | SM_WFC_StairsLower |
| Enclosed Stairs Ceiling | SM_WFC_StairsCeiling |

转换文件与每个文件的哈希、原 Pivot、转换后包围盒保存在 `SourceArt/ProceduralGeneration/WFC/Prepared/conversion_manifest.json`。UE 导入位置为 `/SpiritWFC/Samples/Meshes`。12 个网格全部在 `L_WFC_ModelGallery` 展示，生成地图使用其中的子集。

导入没有复制原项目的美术贴图、完整 Unity 原型连接数据或碰撞代理。示例使用本项目创建的五个简洁材质以及新编写的连接规则。建筑、屋顶和楼梯模型只作为第一轮生成验证素材，不能据此宣称已复刻上游完整城市。

## 可复现流程

在项目根目录运行，路径中的 Python/Blender/UE 可替换为本机安装位置：

```powershell
python Scripts/WFC/download_reference_models.py --revision 8750c537e6c8f95806ba709e2ae5d940fd51bff3
& 'C:/Program Files/Blender Foundation/Blender 3.6/blender.exe' --background --factory-startup --python Scripts/WFC/prepare_reference_meshes.py
# 先正常编译 CrashCourseEditor，随后仅使用编辑器命令行导入/生成。
$wfcProject = (Get-Location).Path
& 'C:/Program Files/Epic Games/UE_5.6/Engine/Binaries/Win64/UnrealEditor-Cmd.exe' "$wfcProject/CrashCourse.uproject" -run=pythonscript "-script=$wfcProject/Scripts/WFC/create_wfc_samples.py" -unattended -nop4 -NullRHI -nosplash -nosound
```

下载脚本优先沿用已有清单的固定版本，不覆盖内容不同的源文件。示例创建脚本默认保留已存在的样例地图；确需重建本插件的三张示例图时，显式附加 `-WFCRebuildSamples`，该操作会重建指定示例，不用于保存用户修改后的地图。可先复制自己的样例变体再重新制作。

生成器和规则可继续使用用户自己的模型；替换时自行保留对应来源及必要通知。正式发布前应确认实际出包中附带的素材通知，而非只保留开发电脑上的源文件。

# 固有疾跑与小镇返回配置

更新：2026-10-24。此轮只改 C++ 与文档，不重存美术关卡、模型或输入资产。

## Shift 固有疾跑

| 项目 | 默认规则 |
|---|---|
| 按键 | 长按左 Shift 或右 Shift |
| 获取 | 初始自带，所有形态可用，不占 1～4 配装槽，不消耗经验或法力 |
| 速度 | 当前 GAS 移速的 1.5 倍；默认 500 → 750 |
| 持续 | 一次最长 5 秒，站立期间也计时 |
| 提前结束 | 松开 Shift 立即结束，然后开始完整 5 秒冷却 |
| 持续到时 | 自动结束并开始 5 秒冷却；继续按住不会自动再次开启 |
| 冷却中按下 | 不开启，也不预存下一次施放；冷却好后松开再按 |
| 中断 | 打开 Tab／N、进入旅行、死亡、失去控制、眩晕或定身时停止，进入冷却 |

如果同时按住两侧 Shift，松开其中一侧仍可继续，全部松开才结束。快速点按也触发完整冷却；已经结束后再松开，不会重新延长冷却。跳跃保持模板动作；疾跑只修改地面最大移速，不增加跳跃高度或飞行速度。

没有新增疾跑动画资产，继续使用当前形态匹配的跑步动作；现有动画父类按实际速度调整播放速率。倍率先用 1.5，正式美术可根据步幅继续调整。

## 蓝图参数与 UI 接口

在 `BP_ProgressionCharacter → Class Defaults → Skills / Sprint` 调整：

| 字段 | 默认值 | 作用 |
|---|---|---|
| `SprintSpeedMultiplier` | 1.5 | 临时移速倍率 |
| `SprintMaxDuration` | 5 | 单次最长持续时间，秒 |
| `SprintCooldown` | 5 | 从结束时开始的冷却，秒 |

参数由所有形态共用，现有蓝图继承即生效，无需额外连线。设置页添加了默认按键说明，Shift 为固定保留键，不纳入六个可改战斗键；1～4、J、E 仍走原配装和改键机制。

后续制作 UI，可从实际玩家 Pawn 调用：

- `SetSprintHeld(true/false)`：输入开始／结束请求。客户端经所属角色 RPC 交给服务器校验；UI 自定义按钮应成对调用。
- `IsSprinting()`：是否正在疾跑。
- `CanSprint()`：当前角色、输入、控制状态及冷却是否允许开始。
- `GetSprintTimeRemaining()`：本次剩余持续时间。
- `GetSprintCooldownRemaining()`：剩余冷却。
- `OnSprintStateChanged(bool)`：开始／结束等状态通知；倒计时用上面的读取接口更新。
- `ResetSprintState()`：仅服务器的初始化／开发重置入口，不放入玩家设置界面。

`ACC_PlayerCharacter` 维护服务器状态，复制活动标志及时间戳，客户端通过 GameState 的服务器时间估算倒计时。当前沿用项目服务器执行路径，没有新增移动预测 SavedMove 方案；延迟和多人移动仍需专项验收。

新增原生 `UCC_SprintEffect`，使用独立 GameplayEffect 句柄乘算 `MoveSpeed`，结束时仅移除这一条效果。不会缓存旧 `MaxWalkSpeed` 再写回，因此不会覆盖变身、永久移速购买、减速或其他加速产生的当前属性。角色销毁／切图会清理效果，避免同一 PlayerState 更换 Pawn 后残留。持续和冷却是当前 Pawn 的临时状态，不写入存档；复活和开发 0／9 预设清空该状态。

## 小镇返回方式

小镇不再自动创建 PlayerStart 旁的回城底座。若存在迁入的旧 `BP_传送门判断`，在小镇运行时关闭其碰撞、隐藏并停止 Actor Tick，不改写关卡美术文件。休憩之地原传送装置继续可用，首次触碰前往小镇并在实际抵达后解锁。

在小镇返回休憩之地或前往山河社稷，按 **N** 打开右侧地图行旅列表，选择已解锁地区并点击“启程传送”。**M** 继续只控制右下角实景小地图显隐；快捷传送沿用既有角色存活、技能就绪、保存和加载检查。

## 验证交接

编译目标：UE5.6 `CrashCourseEditor / Win64 / Development`，日志 `Saved/Logs/SprintTownBuild.log`。按协作约定不启动游戏、不执行运行测试，以下交给前端：

1. 初墨与三条路线都能 Shift 疾跑，速度正确，1～4技能组保持原配置。
2. 按住约 2 秒后松开：立即恢复正常移速，冷却从松开起计满 5 秒。
3. 持续按住超过 10 秒：只跑第一段 5 秒，等待冷却结束也不自动重开；松开再按可重新使用。
4. 冷却期间反复按松：不绕过或延长已有冷却。左右 Shift 同时按下时，松开单侧不提前结束。
5. 疾跑中打开 Tab／N、死亡、失焦、被控制或换 Pawn，确认无残留加速；复活／0／9能回到就绪状态。
6. 不同形态或永久移速加成下结束疾跑，确认恢复当前应有速度；松开疾跑不移除其他速度技能。
7. 小镇出生点不再出现回城底座，N仍能回休憩之地；休憩原装置仍能首次前往小镇。

# 技能界面美术与真实装备配置

更新日期：2026-10-24。UE5.6，测试地图L_FlatTestArena。当前已接真实技能，早期只预览的阶段已经结束。机制参数、默认四槽、解锁规则见[真实技能与铜币配置](真实技能与铜币配置.md)。

## 界面与操作

顶部四分类、中央两列卡片、右侧图标/数值/简介，底部四个真实快捷槽。点击卡片、点击槽位、点“装备技能”，服务器成功后更新CurrentSlots；1～4真正施放所选技能。底部可“恢复当前形态技能组”，清除跨形态保留的手动覆盖。冷却/施法期间不允许换装，相同技能换槽自动交换。

流派未获取时卡片灰显并标注未解锁，装备不可用；服务端装备和实际施放均再次校验。通用始终可用，青铜/古刹/田野分别要求青铜/陶塑/自然之力。角标读取实际改键结果，重新打开菜单仍读取实际组，不生成假预览。

技能页隐藏人物立绘和称号，让出详情区域；其他页面按实际形态恢复。左下不加返回提示，Tab/Esc关闭菜单。装备按钮无额外矩形底板，素材透明通道直接显示详情背景。

## 资源入口

| 资源 | 内容 |
|---|---|
| /Game/UI/MuralMenu/DA_SkillGallery | 18项名称、分类、图标、数值简介及明确的ExecutableSkill引用 |
| /Game/UI/MuralMenu/DA_MenuArt.SkillGallery | 注入上述技能页；清空时回退可配置39项目录的文字页 |
| /Game/UI/MuralMenu/Textures/Skills/Icons | 18张原图，按DesignId命名 |
| /Game/UI/MuralMenu/Textures/Skills/Components | 9张空白组件：4顶部、2卡框、2键位框、1详情框 |
| /Game/HPWH/Skills/Design | 17项新执行资产；通用粒子复用原DA_Skill_01 |

条目字段：DesignId、DisplayName、Category、Icon、StatLabels、StatValues、Description、ExecutableSkill。分类下标0通用、1青铜、2古刹、3田野。图标和文字不决定能力；ExecutableSkill才是实际引用。RequiredFormId在执行资产中配置，不根据中文名猜测。

普通/选中框由CardNormal/CardSelected、SlotNormal/SlotSelected控制，另有DetailPanel与CategoryTabs[0..3]。PNG原件不被改像素，比例和留白通过UMG/UV适配。部分技能可共用现有拳击姿势，具体效果各自执行。粒子技能显示与战斗统一为75%攻击、2秒冷却，保留原规则。

## 脚本

先编译C++。日常换图改数据资产；批量处理时保存并关闭编辑器：

1. configure_skill_gallery.py导入18图标和9组件、更新美术资料，保留已存在的ExecutableSkill引用；不改战斗资产。
2. 从零导入或重建原型之后，最后运行configure_real_skills_and_coins.py补齐真实绑定、39项目录、流派默认四槽、分级奖励与铜币。

来源JSON保存在SourceArt/UI/SkillDesign_v0.1.json。该文件是原始草案；正式粒子75%覆盖说明在实际功能脚本和本说明中，桌面原件不被修改。

## 父类与验证

CC_SkillGalleryData提供展示与执行引用，CC_SkillGalleryWidget负责选择、请求装备和读真实槽位，CC_MuralMenuWidget负责导航与状态回调。能力由GAS执行，界面不直接扣血或加钱。

CC.SkillGallerySmokeTest验证分类/图标、未解锁拒绝和截图；CC.RealSkillsSmokeTest验证菜单装备、1～4实际伤害/治疗、交换、流派校验和各类机制。报告为Saved/SkillGallerySmoke.json、Saved/RealSkillsSmoke.json；截图在Saved/Screenshots/SkillGallery与RealSkills。历史“美术页预览不改变战斗”只适用于接入功能之前的阶段。

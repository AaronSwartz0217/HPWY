# 山河物魄志

东屋藏书。用来辨认旅途中遇到的怪物，也记下器物能借给墨人的三种力量。

## 怪物

### 竹怪

常见于山河社稷。竹路人多在外围巡走，深入后会遇到竹节人和竹拳击手。竹身节段越厚，越要留心它近身出拳。在窄路上遇到一群竹怪时，先给自己留出退路。

### 青铜怪

万象天宫的迷宫里有铜械守卫。它们有小兵、战士、将军等不同档次。留心岔路和墙角，别只顾着追眼前那一只。重排后，路线和守卫的位置都会变。

### 陶塑怪

由陶土塑成，常能从泥色、裂纹和烧制留下的痕迹辨认。旧图记过小陶像与高大的陶身，各有不同的样子。它们在何处出没，画师没有留下确切记录。

### 铜钱怪

小镇和山河社稷都能遇见。它移动时会发出铜钱碰撞的响声，停下时容易和地上的零钱混在一起。击败后可以捡到铜钱，用来购买补给。

## 力量

### 自然、青铜与陶塑

自然之力擅长隐匿、恢复和藤蔓束缚。青铜之力擅长正面守御、蓄力和召唤兵人。陶塑之力能短时护住自身，也能牵引敌人、驱散侵扰。获得对应信物后，可以借用这些形态和本事。

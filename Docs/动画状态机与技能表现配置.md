# 动画状态机与技能表现配置

当前玩家与怪物共用 C++ 表现逻辑，11 个 SOURCE 模型各有自己的 Animation Blueprint。测试仍用 `/Game/HPWH/Maps/L_FlatTestArena`：自然、青铜、陶塑各三档共九个玩家形态；场景十个 NPC 使用青铜/草竹系列。WASD、鼠标视角、空格跳跃保持模板操作，J 或鼠标左键普攻，1～4 释放四个技能，E 交互，Tab 打开背包/进化菜单。

## 先看这些资产

| 项目 | 位置 |
|---|---|
| 模型动画对应表 | `/Game/HPWH/Locomotion/DA_NPCLocomotion` |
| 每个模型的 ABP | `/Game/HPWH/Locomotion/ABP_<模型名>` |
| 重定向动作 | `/Game/HPWH/Locomotion/Animations/A_<模型名>_<动作名>` |
| 普攻数据 | `/Game/HPWH/Skills/DA_BasicAttack` |
| 20 技能数据 | `/Game/HPWH/Skills/DA_Skill_01` ～ `20` |
| 玩家三档 | FormDefinition 的 Stages[0～2]，Mesh/AnimClass/Loadout 分别配置 |

打开任一模型 ABP，AnimGraph 是 `CharacterLocomotion → DefaultSlot → Output Pose`。展开状态机可见 Idle、Run、Jump、Fall、Land、Death。规则读取 `CC_CharacterAnimInstance` 中的实时运动与存活状态；Run 播放倍率按实际速度与 ReferenceSpeed 调整。DefaultSlot 用来覆盖攻击姿势，删除后会出现技能照常结算、人物却不做攻击动作的现象。

源资源审计见 Saved/THATSourceSkeletons.json，77 段新增动作导出见 THATActionsRetarget.json，99 段生成动画比例处理见 AnimationScaleFix.json，11 ABP/九阶段/四个蓝图默认值/十 NPC 引用见 CharacterAnimationSetup.json。

参考源来自 THAT 主角所用的 GameAnimsPack 动画。THAT 的主角蓝图使用 Quinn/MannyGAS 动画体系，原攻击 montage 引用 CrossJab、Uppercut；当前再补入 Jab，以及 Jump、Falling、Land、Death。每个导入模型使用自己烘焙后的动画，未将人形 ABP 直接强套到另一骨架。原资源的伤害/能力通知不复制到新攻击片段，避免和内置 GAS 模板重复结算。

## 配一个模型或替换跑步

1. 在 DA_NPCLocomotion.Entries 中找到 Mesh 对应条目；新模型新增一条，不复用其他模型的记录。
2. 填入同一 Skeleton 的 Idle、Run、Jump、Fall、Land、Death、Jab、CrossJab、Uppercut。
3. 创建/复制 Animation Blueprint，Parent Class 选 CC_CharacterAnimInstance，Target Skeleton 必须与该模型一致，配置六状态和 DefaultSlot。
4. 将 ABP Generated Class 填到条目 AnimClass；RunPlayRate 接 Run Sequence Player 的 Play Rate，ReferenceSpeed 先用 400。
5. 若用于玩家变身，也将相同 Mesh/AnimClass 填入对应 FormDefinition.Stages 档位。三个档位各自配置，不自动继承前一档。阶段已填 Mesh 时，MeshScale 是最终组件相对缩放，直接使用，不乘初始 Pawn 缩放；阶段 Mesh 留空时才按初始模型缩放 × MeshScale 回退。
6. NPC 蓝图保留继承的 Locomotion 组件，Library 指向 DA_NPCLocomotion；不要重复添加组件。

蓝图默认外观也已配置：BP_ProgressionCharacter 为竹路人，BP_PatrolEnemy/BP_ProgressionEnemy 为铜机械小兵，BP_TestDummy 为草竹系列的陶罐头，均带专属 ABP、动画库和约 180 cm 显示尺寸。新拖入或生成这些蓝图即可使用；现有地图十个 NPC 各自模型不变。

需要批量重建时可用 `configure_character_animation.py` 调用编辑器工具 `CC_AnimationSetupLibrary.BuildLocomotionGraph`。它会重建 ABP 图；正式定制后先复制到自己的目录，再修改表格和 FormStage 引用。不要在手工调整后直接重跑覆盖同名图。

`retarget_that_actions.py` 使用完整编辑器 `-ExecutePythonScript` 模式批量导出，`fix_retarget_import_scale.py` 修正 SOURCE 根骨骼导入尺度。SOURCE 根参考比例约为 100，未经修正直接导出可能变得很小或四肢拉长；该修复针对这批模型的参考姿势，不适合无检查地套在任意新骨架上。

## 配技能动作与特效

玩家和怪物均从技能数据读取以下 Presentation 字段，因此同一个技能在不同模型上会选择各自的攻击片段。

| 字段 | 用法 |
|---|---|
| AttackPose | Jab、CrossJab、Uppercut，指向对应模型记录的攻击片段 |
| AnimationPlayRate | 攻击姿势播放速度；只调视觉速度，不自动改变伤害时间 |
| Windup | 前摇秒数，技能成功激活后等待这个时间才执行模板行为；范围 0～3 |
| CastParticles / CastNiagara | 施法时的 Cascade / Niagara，可任选或组合 |
| ImpactParticles / ImpactNiagara | 实际目标/场景命中位置的特效 |
| ProjectileNiagara | 投射物附着拖尾，由投射物生命周期管理 |
| EffectScale / EffectLifetime | 视觉缩放、瞬时施法/命中特效保留时间 |

当前普攻 Windup 为 0.12 秒，技能约 0.16～0.22 秒，都是可编辑占位参数。伤害来自服务器模板；攻击片段不承担扣血。Windup 应对准各自视觉动作的命中位置；修改 AnimationPlayRate 后也要重新校准 Windup。GroundStrike 还会额外使用自身 Interval 延迟，Combo/DamageZone 则由模板按 Count/Interval 继续执行。中断能力会取消等待任务并停止 montage；换技能组也会取消旧表现。

当前施法/命中占位效果来自 StarterContent 的 Sparks、Dust、Steam、Explosion 等，投射物使用已迁入的 LanTuRebuild MixedVFX Projectile_01 及其 Hit。正式资源准备好后只需要改数据引用，不需要为每个名字新增 C++ GA。音效、技能图标、自定义投射物蓝图类目前仍需后续开发。

表现由服务器调用 Locomotion，Multicast 播放姿势和瞬时特效，投射物复制技能定义后在各端创建 Niagara。视觉事件不参与伤害判定；专用服务器跳过视觉创建。已接入复制路径不代表已经完成双客户端验收。

## 死亡后交给物理

Death 状态先播放倒地动作，默认 0.65 秒后 CC_BaseCharacter 将 Mesh 切到布娃娃物理。敌人从死亡起 10 秒后销毁，经验粒子独立存在直到领取或超时；复活会停止物理并还原挂接/碰撞/移动。配置字段、Physics Asset 要求和经验掉落见[死亡布娃娃与经验粒子配置](./死亡布娃娃与经验粒子配置.md)。

## 测试与问题定位

日常打开平地场，先测试移动与空格，再用 J/鼠标左键和 1～4 观察动作及特效。青铜/陶塑拾取后、进化后分别检查新模型；自然形态可以直接进化。出现跳跃漂浮时检查 Jump/Fall 是否接反和根位移，出现技能没有动作时检查当前 Mesh 的 AnimClass、DefaultSlot 和 AttackPose 对应片段。

专用测试进程可执行：

```powershell
& 'C:\Program Files\Epic Games\UE_5.6\Engine\Binaries\Win64\UnrealEditor-Cmd.exe' `
  'C:\Users\29717\Desktop\GASCrashCourse-main\GASCrashCourse-main\CrashCourse.uproject' `
  /Game/HPWH/Maps/L_FlatTestArena -game -unattended -RenderOffscreen `
  -ResX=1280 -ResY=720 '-ExecCmds=CC.AnimationSmokeTest' -log
```

测试约 14 秒，自动退出并写 `Saved/AnimationSmoke.json`。它采样实际状态机节点的 Jump/Fall/Land/Run，检查场上玩家/NPC 的 ABP 和动画骨架、实际技能激活与 montage、临时无碰撞投射物 Niagara、施法/命中特效组件，以及前摇取消后不扣血且停止 montage；未取消的对照技能则先等待、到时再扣血。它使用零经验的临时靶和临时技能组，不执行进化、购买或保存；结束前恢复玩家技能组。

渲染模式另外输出 `Saved/Screenshots/AnimationJump.png`、`AnimationAttack.png`、`AnimationEffect.png`。将 -RenderOffscreen 换成 -NullRHI 可以先检查状态与逻辑，但报告会明确标记跳过实际渲染效果检查；无渲染通过不能作为特效验收。

`CC.PatrolSmokeTest` 继续检查范围巡逻、跑步、发现、追击、返回和死亡停止；已支持新的 ABP 跑步状态。测试命令会改变专用进程里的位置/AI 并自动退出，不要在正在制作资源的编辑器会话中运行。

基础六状态与全身攻击 Slot 已有配置。接下来优先校准实际攻击距离与命中帧、20 技能正式命名和数值，再替换正式特效；转向、受击分层、连招窗口、脚部 IK 和根运动攻击属于后续打磨。

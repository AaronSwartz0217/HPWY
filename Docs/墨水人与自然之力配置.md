# 墨水人与自然之力配置

本轮初始角色改为“墨水人”。当前沿用原始模板人物的模型轮廓，生命为 75、攻击为 11.25；法力仍为 100、移速仍为 500。模型材质留给后续美术配置。

## 游戏操作

1. 新角色进入测试平地时使用墨水人。
2. 靠近白色方块按 E，获得自然之力并存入背包。绿色方块获得青铜之力，黄色方块获得陶塑之力。
3. 交互只取得元素之力，不立即变身。按 Tab 打开背包，选择已取得的元素之力并使用，才切换到该路线已有的档位。
4. 切换到自然之力后，100 经验购买中级、1000 经验购买高级；分别变为竹节人与竹拳击手。
5. 在背包选择恢复墨水人时调用 SwitchForm(空)，自然、青铜、陶塑各自已买档位继续保留。

墨水人本身没有购买进化，必须先通过元素方块取得路线。永久生命、攻击等购买仍可按商品配置作用于所有形态；“75%”指未买加成时的基础生命和攻击。

## 编辑器配置位置

| 位置 | 用途 |
| --- | --- |
| `/Game/HPWH/Forms/DA_Form_InitialInk` | 初始形态。FormId=InitialInk、Available=true、CanEvolve=false。 |
| `/Game/HPWH/Characters/SK_InitialInk_Template` | 复制出的独立初始模板网格体。以后在这里的 Materials 槽指定黑色材质即可，不会修改导入的模板原件或其他形态。 |
| `/Game/HPWH/Locomotion/ABP_InitialInk_Template` | 初始角色六状态动画图及 DefaultSlot 攻击插槽。 |
| `/Game/HPWH/Loadouts/DA_Loadout_InitialInk` | 初始四技能组；手动配置技能仍由现有技能目录控制。 |
| `/Game/HPWH/Forms/DA_Form_Native` | 自然路线。名称沿用旧资产名，稳定 FormId 仍为 Native，避免破坏存档。 |
| `/Game/HPWH/Balance/DA_CombatBalance` | InitialInk 行的生命倍率和攻击倍率均为 0.75；自然三档沿用 Nature_T1/T2/T3。 |
| `/Game/HPWH/Blueprints/BP_Artifact_Nature` | 白色自然方块父蓝图，Artifact.Form 指向 DA_Form_Native。 |
| `BP_ProgressionPlayerState → Progression` | NativeForm 指向 DA_Form_InitialInk；ArtifactForms 在原有目录后追加 DA_Form_Native。青铜与陶塑前两项的顺序保留。 |

初始形态的数据结构仍有三项 Stage，以兼容固定三档的资产校验；三项内容相同，只使用第 0 项。CanEvolve=false 同时在服务器侧拦截进化请求，隐藏按钮不会成为唯一限制。

自然路线的基础值如下，不包含永久购买和临时效果。

| 档位 | 模型 | 生命 | 攻击 | 进入费用 |
| --- | --- | ---: | ---: | ---: |
| 初级 | 竹路人 | 100 | 15 | 方块取得后使用 |
| 中级 | 竹节人 | 250 | 37.5 | 100 经验 |
| 高级 | 竹拳击手 | 450 | 67.5 | 1000 经验 |

白色方块在现有测试地图的 `(0,-750,60)`。已有场景和其他器物不重建，神秘／墨化路线保持未开放；“墨水人”与未来的“墨化之力”使用不同 FormId。

## 接 UI 的接口

- `Progression.Forms` 是已经取得的元素之力及其档位；背包枚举它来生成“使用”按钮，不直接枚举 ArtifactForms 当作已取得。
- `Interact(Actor)` 由服务器检查距离、视线、资产完整性与目录，成功后增加 Forms 并发出 OnChanged 和 OnPurchaseFinished(Success)，不改 CurrentForm 或 CurrentTier。
- 背包使用按钮调用 `SwitchForm(Form)`；恢复初始墨水人调用 `SwitchForm(空)`。等待 OnChanged 后根据实际状态刷新角色图与称号。
- `GetActiveForm()` 返回实际有效形态；初始时是 DA_Form_InitialInk，绝不能用“CurrentForm 为空”显示自然之力。
- `CanEvolveCurrentForm()` 表示该形态和档位能否进化，不包含余额检查；`GetEvolutionCost()` 在墨水人和最高档返回 -1。余额检查由 Evolve 的服务器处理。
- 当前实战生命、攻击从 ASC 读取；预览使用 GetStagePreview，并根据 Form.CanEvolve 决定是否显示下一档。

菜单立绘、称号应读取 `GetActiveForm().Stages[CurrentTier]` 的 MenuPortrait、MenuTitle、MenuDisplayName。取得尚未使用的元素之力时，当前立绘保持墨水人；使用或进化完成以后再更新。

## 本地存档兼容

新存档版本为 2，新增 NativeFormId，明确原生档位属于哪种初始形态。经验、背包路线、各路线档位、手动四技能与永久购买继续保存。存档仍由现有 SaveProgress／LoadProgress 手动执行，后端接口依旧只同步经验。

读取版本 1 旧档时，旧 NativeTier 迁到自然之力，自动保留此前始终可用的自然路线；旧档选择原生时改为选中自然之力，旧档选择青铜／陶塑时保持选择。墨水人始终为第 0 档，经验不扣减。如果自然路线目录未配置好，读取直接失败并保留当前余额，避免部分迁移丢数据。

## 开发检查

先完成 C++ 编译，再在 Unreal Python 环境运行 `Scripts/configure_initial_ink_nature.py`。脚本可重复运行；只保存 HPWH 的新配置、专用初始动画资产及现有平地地图，不修改导入原件。首次运行会针对原始模板骨架生成九段动作和六状态动画图；菜单图片配置脚本应在它之后执行。

运行自动测试 `CrashCourse.Progression.InitialInkAndNature`：检查 75/11.25 初始值、初始不能进化、交互仅入背包、显式使用才变身、100/1000 自然档位费用、版本 2 往返和版本 1 兼容迁移。核心 `CrashCourse.Progression.TransactionsAndDamage` 同时检查器物获取不自动切换以及独立档位保留。

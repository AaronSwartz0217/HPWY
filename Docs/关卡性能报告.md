# UE5 关卡性能报告

## 60 FPS 帧预算

60 FPS 的单帧预算为 16.67 ms。两张地图各运行两次，按「没有优化 → 场景优化 → 场景优化 → 没有优化」顺序。每次舍弃启动段前 350 帧，保留 1050 帧。使用 1920×1080 启动参数、100% 渲染比例和未锁帧模式，镜头停在各地图默认出生视角。此次没有逐帧核实实际视口尺寸。两图 GameMode 不同，结果代表整图差异。

| 指标 | 没有优化 | 场景优化 |
|---|---:|---:|
| 平均总帧时间 | 12.71 ms | 10.17 ms |
| P95 总帧时间 | 15.12 ms | 12.04 ms |
| P99 总帧时间 | 17.39 ms | 12.90 ms |
| 超过 16.67 ms 的帧 | 38/2100（1.81%） | 3/2100（0.14%） |
| 平均渲染线程耗时 | 12.79 ms | 10.16 ms |
| 平均 GPU 耗时 | 7.68 ms | 7.10 ms |
| 平均 Draw Calls | 2882 | 741 |

优化图 P99 留出 3.77 ms 预算。三帧超预算均来自第一轮，该轮最大 22.57 ms，第二轮最大 14.14 ms。固定视角的收益主要与渲染线程耗时下降同步。转镜头时的瓶颈还需独立采样。

## 同场景门控验证

在「场景优化」同一进程、同一固定镜头切换门控，实际视口为 888×500，各取 800 帧。平均总帧时间 13.15 → 11.00 ms，GPU 7.60 → 7.12 ms，Draw Calls 1325 → 798。该轮验证了门控本身的局部收益。已有截图记录瞬时统计。

## 复测路线

在目标分辨率运行两图，分别记录首次左右扫视、重复扫视、开门进出房间三个片段。对比 P95、P99、超预算帧占比，并对尖峰附近的 Game、Draw、GPU 耗时做同步对照。单独保存锁 60 FPS 的运行结果。

## 1080p 实拍复测

两张关卡均使用 CC_AdventureGameMode 与 Lumen GI High，串行运行并各取 750 帧，保留各自默认出生视角。

| 指标 | 没有优化 · 原生 TAA | 场景优化 · DLSS Quality |
|---|---:|---:|
| 平均 FPS | 67.12 | 84.95 |
| 平均总帧时间 | 14.90 ms | 11.77 ms |
| 平均 GPU 耗时 | 12.75 ms | 9.51 ms |
| 平均 Draw Calls | 3213 | 726 |
| P99 帧时间 | 17.31 ms | 14.58 ms |
| 超过 16.67 ms | 2.00% | 0.40% |

该组数据包含关卡和升采样设置的综合差异。另一次两图同用 TSR 80% 的复测中，平均 FPS 为 61.43 → 67.44，P99 为 20.39 → 16.69 ms，Draw Calls 为 3228 → 724。

游戏内通过 Tab → 设置 → 画质切换 TSR 80% 或 DLSS Quality。DLSS 是可选插件，需要在项目 Plugins 下安装 NVIDIA 官方 UE 5.6 版的 DLSS 和 StreamlineNGXCommon。本仓库提供画质切换代码。未安装插件或设备不支持时，可使用 TSR。

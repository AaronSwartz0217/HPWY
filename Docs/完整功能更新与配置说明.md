## 1. 当前可以做什么

当前流程：**独立首页 → 开始游戏进入休憩之地并恢复进度 → 探索或传送至平地测试场 → 靠近信物出现拾取提示 → E 释放能力球 → 实际领取后力量存入格子背包 → 选择使用或进化 → 普攻/四技能战斗 → 领取经验粒子 → 购买成长 → 启动/切图存档及设置页手动存读**。最新首页与音乐由前端安排运行验收。

## 3. 启动与操作

| 操作 | 行为 |
|---|---|
| WASD、鼠标、空格 | 模板移动、视角、跳跃 |
| J / 鼠标左键 | 独立近战普攻，不占四槽 |
| 1 / 2 / 3 / 4 | 施放当前实际四槽技能 |
| 长按 Shift | 固有疾跑，默认1.5倍移速、最多5秒，结束后冷却5秒 |

| Tab | 打开/关闭壁画菜单 |
| Esc | 关闭菜单；录入按键时由按键选择控件先处理 |

菜单打开时锁定角色移动、镜头和战斗操作，**世界和怪物继续运行，不暂停**。原左下“返回游戏 Tab/Esc”按钮/提示已移除；左下只在有效交互范围内出现拾取图片。经验余额仅显示在背包页，不放在主页或其他功能页。

### 建议首次验收顺序

1. 打开L_MainMenu后Play，开始游戏进入休憩之地；无存档且零经验时初墨生命75、攻击11。N可选择默认解锁的山河社稷测试场。
2. 靠近蓝黄色/黄棕色/绿色信物方块，看到左下拾取提示，按E释放同色能力球。
3. 等能力球实际吸附，确认力量入包且经验+50；初墨属性随余额强化。Tab → 背包查看。
4. 选中元素 → 切换形态，观察人物、属性、立绘和右上称号更新。
5. 击杀怪物或领取黑包经验，等待粒子实际吸附；查看背包余额。
6. 选中当前形态进化：100经验到中级，再1000到高级。切换路线后再切回，档位应保留。
7. 技能页选卡、选槽、装备并关闭菜单，按1～4验证实际效果；对应流派未获取时应锁定。
8. 碰触场景五铢钱，背包确认铜币+1、经验+5；手动存读档确认铜币保留。
9. 设置页手动保存/读取角色进度，确认当前形态和成长记录恢复。

## 5. 器物标记、范围拾取与提示

已有场景物体蓝图可挂 **CC_ArtifactComponent**，在 Form 指定对应形态。不强制所有物体重继承同一个父蓝图，也不靠字符串标签决定变身。需要直接放置时可继承 **CC_FormArtifact**，已有 Mesh 与 Artifact 组件。

交互步骤：客户端选目标 → 权威逻辑复核有效性、距离、视线与目录 → 将力量加入 Forms → 通知UI。不会在交互时直接切换模型；重复获取不重复添加。

| 判定/提示 | 当前规则与作用 |
|---|---|
| 瞄准优先 | 相机射线命中的目标若可交互，优先处理 |
| 附近兜底 | 未瞄准有效目标时，在角色周围搜索候选，按距离并参考视野方向选目标 |
| 搜索半径 | 控制器 NearbyInteractionSearchRadius 默认450厘米，只决定候选搜索范围 |
| 实际可达距离 | 器物/经验包 InteractionDistance 默认250厘米，按玩家位置到可碰撞组件包围盒最近表面计算 |
| 遮挡/状态 | 隔墙、超距、死亡、禁用器物、已消耗经验包不能交互；服务器再次校验 |
| 左下拾取图 | 与E键共用 FindInteractionTarget；只有有效目标时显示，菜单开启时隐藏 |

默认交互图包含E；改交互键后会额外显示实际按键，若要完全统一图中文字可替换纹理。原PNG保留在 `SourceArt/UI/E_Pickup.png`，纹理是 `/Game/UI/MuralMenu/Textures/Interaction/T_Prompt_Pickup`，在 BP_MuralHUD.PickupPromptTexture 配置。

## 6. 经验、死亡与粒子

- 低级/中级/高级/精英奖励分别为10/40/200/500经验，来自CombatBalance.Profiles.ExperienceReward；敌人尸体10秒后消失。
- 单次最多128颗经验Actor，200/500总额均分到每颗，保持总奖励并限制场景开销。陶罐头继承自然高级200经验。
- 新五铢钱碰触后播放音频并消失，直接发放1铜币、5经验；铜币在背包显示并随v3本地进度保存。
- 五铢钱沿用原动画状态机/混合空间；Character父类使用重力、胶囊与地面检测，模型置于胶囊底部。出生点600厘米内导航巡逻，速度100厘米/秒，每次等待1～3秒；正式地图需构建导航。
- 当前平地测试场已保存Arena_NavMeshBounds与RecastNavMesh-Default，导航范围约118×118米，运行时动态生成并在加载时重建。按P查看绿色可行走区域；导航寻路与角色贴地分别由NavMesh和CharacterMovement处理。
- 黑色经验包E交互放出50颗粒子，共50经验；默认非重复消费，已有状态防止连续重复领取。
- 经验粒子使用Niagara视觉，运行逻辑由服务器控制：散射 → 追向领取者 → 与正确角色实际接触后消失并逐颗入账。
- 粒子刚飞出时钱包不预加10/50；未接触、领取者不匹配或无效状态不发经验。到期未领取的粒子会回收。
- 死亡停止技能与相关行为，死亡动作衔接模拟物理布娃娃；复活入口负责还原网格、碰撞、动画与移动。

这将奖励、视觉与实际到账分开，方便以后换Niagara、音效和表现而不改经验结算。

## 7. 实际战斗技能与装备页

默认技能页已接通真实装备，不再是预览。18项图标通过FCC_SkillGalleryEntry.ExecutableSkill明确引用CC_SkillDefinition，服务器EquipSkill成功后读取CurrentSlots刷新；1～4触发各自Spec/InputID。可交换技能、恢复当前形态默认组，手动组随存档和变身保留。

| 分类 | 技能与实际行为 |
|---|---|
| 通用6项 | 直拳单目标、连拳三击不同系数、横扫、重拳、75%粒子、20%最大生命治疗 |
| 青铜4项 | 三个实体兵人、临时攻击/防御强化、按住/松开的蓄力一击、正面防御 |
| 古刹4项 | 金身免伤、重力牵引/两段伤害、六轮范围伤害、驱散/护盾 |
| 田野4项 | 隐身/提速与破隐、8次持续回血、直接实际伤害吸血、区域伤害/定身 |

通用默认解锁；青铜/古刹/田野的RequiredFormId分别为Artifact_01/Artifact_02/Native，需吸收蓝黄色青铜/黄棕色陶塑/绿色自然信物释放的能力球。当前形态可以不同，已获取流派可跨形态手动使用。UI灰显未解锁项，装备RPC和GAS实际激活再次核验；旧存档中不合法的配装会丢弃并恢复默认组。

默认四槽：初墨=直拳/连拳/横扫/回复术；自然=天人合一/草木之灵/生生不息/藤缚地牢；青铜=召唤兵人/暂时进化/蓄力一击/铜阵守御；陶塑=无相金身/重力控制/佛光千盏/莲华净障。已有手动组优先，点底部恢复按钮再回形态默认。

原22项在DA_Skill_01～22保留，新设计在Skills/Design增加17项并复用原01粒子，共39项可配置资产。普攻DA_BasicAttack独立，不占四槽。旧模板可由接口或文字回退页配置，旧ID不改变。正式粒子保持当前攻击75%，不采用早期美术草案160%；目标防御按100/(100+防御)处理，先扣护盾，再扣生命。

蓄力使用真实按下/释放事件，松开或2秒满蓄打出，打出后12秒冷却；被取消为3秒失败冷却。召唤兵人有生命、跟随/攻击、归属和60秒生命周期，不是只有粒子。金身、方向防御、隐身、控制、治疗与实际伤害吸血均有独立状态逻辑。

完整参数、单机限制、流派与默认组配置见[真实技能与铜币配置](真实技能与铜币配置.md)。技能图标/框体入口仍为DA_SkillGallery，详见[技能页美术配置](技能界面美术配置.md)。

## 9. 敌人AI、模型动画与相机

CC_PatrolEnemyCharacter 可派生普通怪/精英蓝图，管理出生中心范围巡逻、到点等待、警戒、追击、按距离/冷却尝试四技能、脱战返回和死亡停止。导航由测试场NavMesh提供，运行初期需等待导航就绪。

普通敌人使用近战技能组，不再作为默认远程炮台；精英三近战+粒子远程。每个敌人按共享数值表解析其档案。场景中原10个NPC含巡逻敌人与被动靶子，另有两类精英配置。

模型/动画配置包括骨骼匹配的专属ABP、待机/跑步/跳跃/下落/落地/死亡基础状态，以及Jab/CrossJab/Uppercut攻击姿势。初墨使用独立模板网格与匹配动画，不会为换黑色材质影响其他模型。当前攻击Slot、前摇、动画速率和施法/命中/粒子特效可配置；精细连招、方向受击、移动分层、IK和音效仍需继续制作。

C++ SpringArm 负责第三人称相机避障；相机过近时隐藏玩家网格并在恢复距离后显示。模型/Capsule不阻挡自身相机；场景障碍需要正确配置Camera碰撞响应。

## 10. 本地存档与经验后端

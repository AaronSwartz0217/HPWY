# 砚边旧记

西屋藏书。每个世界占一页。

## 休憩之地

一座有厢房的院子，也是你醒来的地方。屋里有三册书，分别记着各地、怪物和画师留下的线索。院门口的旧传送门通往小镇。从这里出发，也可以回来歇息。

## 小镇

沿街有客栈、铜铺、陶坊、竹行和旧纸摊。客栈可以休整，几家铺子各有药水或锻炼项目，旧纸摊出售前往其他世界的传送卷轴。巷子里偶尔有铜钱怪。准备好补给和对应的卷轴，再往外走。

## 山河社稷

这里有竹林、岩石和相连的小路。起点附近多见竹路人，深入后会遇到竹节人和竹拳击手，有时也能碰见铜钱怪。越往外走，竹怪越难对付。初次进山，可以先沿近处的小路辨清方向。

## 万象天宫

抵达时先进入方块墙围成的迷宫，青色庭院是起点。路上有铜械守卫，踏上黄色区块才解锁都市建造。重建后能看到广场、街巷、不同样式的屋舍和浮台。重排迷宫会改变路线，并将旅人送回入口。

## 宫殿

这是画师在图上记下的第五处。图上的路只画到殿门，门内还是空白。旧纸摊有通往宫殿的卷轴。殿里有什么，先留待踏进门后再记。

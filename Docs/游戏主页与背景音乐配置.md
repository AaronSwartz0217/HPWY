# 游戏主页与背景音乐配置

更新：2026-10-24。游戏主页是独立地图，游戏内 Tab 菜单仍使用原有背包、技能、交易和设置。

## 启动与操作

| 项目 | 当前配置与作用 |
|---|---|
| 默认启动地图 | `/Game/UI/MainMenu/Maps/L_MainMenu`，独立空关卡，仅绘制首页 |
| 首页模式 | `ACC_MainMenuGameMode`，使用 `ACC_MainMenuController`，不生成玩家Pawn，使用空AHUD |
| 首页内容 | 现有 Logo、无人物纯石壁云纹背景、开始游戏／宣传网站／退出游戏 |
| 开始游戏 | 无存档时使用初墨初始数据；有有效本地档时恢复永久进度，进入休憩之地 |
| 宣传网站 | 点击直接由系统浏览器打开 `https://aaronswartz0217.github.io/Spirit-Tales/`；无联系弹窗 |
| 退出游戏 | 调用引擎 QuitGame；在编辑器内通常结束本次游玩 |

`GameDefaultMap` 与 `EditorStartupMap` 均设为首页。重新打开工程后默认加载 L_MainMenu，点击 Play 显示游戏首页；已经运行中的编辑器不会自动切换当前地图，需要自行打开 L_MainMenu 或重开工程。在编辑器点击 Play 仍运行当前打开的地图。打包列表包含首页和三个游戏地区，同时保证首页素材与音乐目录进入 Cook。

开始游戏没有清档入口，不会在首页先覆盖存档。存档损坏或版本不支持时显示错误并保留原文件；目标地图不存在时留在首页。异步读图显示实际读取百分比，世界初始化显示等待进度条。失败时恢复开始前的内存快照，成功进入且角色状态就绪后沿用既有保存流程。

## 更换首页美术和网址

编辑 `/Game/UI/MainMenu/DA_HomeArt`，类型为 `UCC_MenuArtData`：

| 字段 | 配置 |
|---|---|
| `Background` | 默认 `/Game/UI/MainMenu/Textures/T_Home_WallOnly` |
| `Logo` | 复用 `/Game/UI/MuralMenu/Textures/Menu/T_Menu_Logo` |
| `StartupLogo` | `/Game/UI/MainMenu/Textures/T_Home_StartupLogo`，黑底开场图，显示2秒后淡出1秒 |
| `WebsiteURL` | 完整 HTTP/HTTPS 地址；当前为 `https://aaronswartz0217.github.io/Spirit-Tales/` |
| `SkillGallery` | 首页留空，避免加载游戏内技能美术 |

背景覆盖窗口，Logo 和三个按钮按 1920×1080 等比适配，标题与三项菜单沿中央轴纵向排布，纯壁画铺满背景。更换图片时保持左侧留白。背景实际原图为 1672×941，并非 4K；原图和生成说明保存在 [SourceArt/UI/MainMenu](../SourceArt/UI/MainMenu/README.md)。游戏内 `DA_MenuArt` 继续单独配置，改首页不影响 Tab 页面。

2026-10-25 修复主页按钮文字异常折行：按钮内容槽水平铺满，文字固定单行、垂直居中，保持现有按钮坐标与字号。部署既有工程网址可运行 `Scripts/configure_home_website.py`，仅修改 `DA_HomeArt.WebsiteURL`，不启动游戏或修改存档。`configure_game_home.py` 初始化时会把空地址或旧仓库地址迁移到宣传站，保留其他自定义地址。

需要使用 Designer：创建 `UCC_MainMenuWidget` 派生 Widget Blueprint，调用 `StartGame / OpenWebsite / ExitGame`。在派生 `ACC_MainMenuController.MainMenuClass` 中指定控件，并由派生主页 GameMode 指定 Controller。若更换主页 GameMode，需要同步 `UCC_AdventureGameInstance.OverrideGameModeClass` 的主页返回类；目前该入口返回原生类。

## 全局背景音乐

当前采用用户指定的“文物展示关卡”配乐，源项目为数媒交互文化主题项目模板，资源名“游戏配乐萌新写的多利亚练习小曲儿_音频”。已迁入独立 `/Game/Audio/Music/SW_ExhibitionTheme`，约128.405秒并启用循环，源文件保持不变。此前LanTu的Starter音乐保留但不再作为默认背景音乐。详见[开场与材质提示处理](开场Logo与材质提示处理.md)。

由 `UCC_AdventureGameInstance` 持有唯一音频组件，首页／游戏地图就绪时调用 `EnsureBackgroundMusic`，播放中的组件复用。采用无空间衰减的 2D 音乐、跨关卡持久化、非自动销毁；Tab 菜单、旅行暂停期间保持播放，GameInstance 结束时停止并销毁。没有往三个关卡分别放置重复音乐 Actor。

可在 `Config/DefaultGame.ini` 添加以下段落调整默认值，无需重编译。替换音乐时应使用已设置循环的 SoundWave 或循环 SoundCue，并把新资产加入 Cook。

```ini
[/Script/CrashCourse.CC_AdventureGameInstance]
BackgroundMusic=/Game/Audio/Music/SW_ExhibitionTheme.SW_ExhibitionTheme
BackgroundMusicVolume=0.25
MusicFadeInSeconds=1.5
```

`SetBackgroundMusicVolume(0..1)` 留作以后音量 UI 的蓝图接口；当前只调整会话音量，不写新的用户设置档。没有增加音量设置界面。此音乐先作为统一基调占位，未新增混音或地区切换曲目。

## 小地图与游戏模式核对

小地图独立锚定真实 viewport 的右下角，锚点与对齐均为 `(1,1)`，向内留 16 个 UMG 逻辑单位，面板 334×376、摄像机画面 256×256；超宽屏不再跟随居中的 16:9 画布缩进。N 行旅页面仍保留原布局，M 显隐行为不变。

三张注册地区仍由 `UCC_AdventureGameInstance.OverrideGameModeClass` 统一返回 `ACC_AdventureGameMode`。World Settings 保存的旧模式会被这个运行时入口覆盖；本轮不重存美术关卡。最新用户游玩日志已记录测试场和初始房间使用 `CC_AdventureGameMode`；小镇按相同路径映射核对，未运行传送测试。应使用 `CC_AdventureGameInstance` 启动工程，其他地图维持原模式。按用户要求，本轮不继续处理旧蓝图的 Damage Actor 引脚警告。

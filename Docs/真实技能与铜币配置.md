## 技能页怎么操作

1. Tab → 技能，选择顶部分类与技能卡。
2. 点击底部1～4的一个槽位，再点“装备技能”。看到成功反馈后，关闭菜单按对应键使用。
3. 实际槽位由角色技能组件CurrentSlots读取，界面不会先画一个成功图标冒充服务器已装备。
4. 灰色卡片标注“未解锁”；对应流派未开放时不能装备，即使直接请求RPC或额外授予GA也不能绕过施放校验。
5. 施法中或冷却期间不能更换装备。一个技能不能占两个槽；换到另一个槽会交换原技能。
6. 手动组会跨变身保留；需要使用新形态默认四技能时，点击“恢复当前形态技能组”。
7. 通用技能始终可用；获取力量后可以跨形态手动装备该流派技能，不要求正在使用该形态。

原名PreviewEquip/GetPreviewEntry保留以兼容现有调用，当前语义已经是请求真实装备和读取真实槽位，不再是预览功能。

打开`/Game/HPWH/Balance/DA_CombatBalance → Profiles → ExperienceReward`：

- T1=10，T2=40，T3=200；两类Elite=500。

- 敌人经验继续实际吸附接触入账。单次最多128颗Actor，超过128的奖励均匀分摊到每颗，确保200/500经验总额正确并控制性能；黑包仍50颗/50经验。
- 数值/路线老脚本重建后，最后运行configure_real_skills_and_coins.py恢复本轮奖励和技能引用。

## 铜币怎么配

蓝图：`/Game/HPWH/Coins/BP_CopperCoin`，父类CC_CoinPickup。场景已放5个，标签CopperCoin_Test_00～04。

| 字段 | 当前值与作用 |
|---|---|
| CopperAmount | 5，碰触获得的铜币 |
| ExperienceAmount | 5，碰触直接获得的经验 |
| PickupSphere | 半径90厘米，只对Pawn产生Overlap；服务端检查真实距离、存活状态及PlayerState |
| CoinMesh | SK_WuzhuCoin，约80厘米高 |
| CoinMesh.AnimationMode / AnimClass | AnimationBlueprint / ABP_WuzhuCoin_C，保留原状态机与BS_WuzhuCoin速度混合 |
| CapsuleComponent / Mesh偏移 | 半径24、半高42厘米；模型相对Z=-42、Yaw=-90，模型脚部随胶囊底部落地 |
| PatrolRadius / PatrolSpeed | 出生点周围600厘米、100厘米/秒，沿可达导航路径巡逻 |
| MinPatrolWait / MaxPatrolWait | 每次移动前随机等待1～3秒，待机/行走动画读取实际速度切换 |
| bStartPatrolling / AutoPossessAI | true / PlacedInWorldOrSpawned；服务端执行，可调用StartPatrol/StopPatrol |
| PickupSound | S_WuzhuCoin_Pickup，接触后播放，移除Actor后音效继续 |

复制蓝图放到场景即可，不需要E键。bCollected及关闭碰撞保证重复Overlap只结算一次。不是角色的Actor、远程调用、死亡玩家和客户端本地碰触不能直接增加余额。

素材归类在`/Game/HPWH/Coins/Art`。现有12个资源：模型、两段24fps动画、声音、材质、骨架、物理资产、贴图，以及本次补迁的原动画蓝图ABP_WuzhuCoin和混合空间BS_WuzhuCoin。保留原“New State Machine → 跑”及速度驱动逻辑；speed来自TryGetPawnOwner的实际速度，静止混待机，移动混走路。来源UE5.5，已在UE5.6加载/重存，无须重新转格式。旧积分Widget与旧金币Actor蓝图不运行，奖励由当前C++结算。

当前父类改为Character，CharacterMovement负责重力、地面检测与台阶，胶囊体承担地面碰撞。此前仅有拾取Sphere且模型位于Actor中心，造成没有移动逻辑和悬空；现在模型置于胶囊底部，场景五个铜钱也已重新贴地摆放。正式关卡需要覆盖铜钱区域的NavMeshBoundsVolume并构建导航（P键检查绿色区域）；无导航时等待重试。蓝图的移动组件MaxWalkSpeed运行时由PatrolSpeed统一设置。半径以出生位置为中心，避免原蓝图不断相对当前位置选点造成越走越远。

当前L_FlatTestArena使用Arena_NavMeshBounds，中心(0,0,150)、半尺寸(5900,5900,400)厘米，约覆盖118×118米。已补存RecastNavMesh-Default，RuntimeGeneration=Dynamic、ForceRebuildOnLoad=true；导航负责选路绕障碍，CharacterMovement负责实际行走和贴地。高处出生先落地，巡逻选点时将中心向导航面投影。更换/扩大地图时同步调整导航范围，编辑器按P查看覆盖，并在Build菜单执行Build Paths。

后端目前不存铜币，通过本地SaveGame保存。现已增加五种铜币药水、数字5道具栏和分档怪物击杀铜币，详见[药水商店与道具栏](药水商店与道具栏.md)。服务器云同步或账号系统仍未接入。

## 派系实战配合更新

本轮保留十二个派系技能的倍率、持续时间和 CD，强化具体用法：

- 青铜兵人优先攻击主人最近直接攻击的目标，主人受击且没有主动目标时协助防卫。指令记忆 6 秒，仍受原侦测距离、视线、目标存活与隐身限制；失去有效指令后恢复就近选择。暂时进化的攻防增益仍由兵人实时继承。
- 铜阵守御可中断当前前台攻击并立即开启，保持正面 120 度、5 秒、200% 基准防御与原有 CD；不会降低已经更强的防御。眩晕中不能用守御。
- 无相金身可在受控时立即施放，并中断当前前台动作，提供原有 2 秒免伤与控制免疫；不移除旧负面效果，结束后尚未到期的效果仍继续。
- 重力场和藤缚区域在找到有效地面时贴地落点；佛光、重力场与藤缚的范围命中忽略区域内其他角色的遮挡，仍检查墙体视线。
- 藤缚的单次 120% 攻击力伤害归为玩家直接伤害，可触发生生不息；仍受实际生命伤害、20% 转化与每秒 8% 最大生命上限约束。召唤物、持续脉冲及护盾吸收继续排除。
- 草木回复等非伤害技能保持天人合一；主动藤缚等伤害技能会破隐，原有期限和加速不变。

技能卡说明、SkillDefinition.Description 与 SourceArt/UI/SkillDesign_v0.1.json 已同步，数值字段不变。说明维护脚本为 Scripts/update_faction_skill_descriptions.py。

## 玩家“发射粒子”的瞄准与可读性修正

复现中水平释放能够生成弹体；向下俯视时，弹体可能迅速击中脚前地面。现在无显式目标的玩家投射技能使用实际镜头射线，并从角色深度开始查询，避免把第三人称镜头后方的障碍当成前方目标。AI 或有明确目标的技能沿用原有目标逻辑。发射口距离考虑缩放后的胶囊半径；瞄准、枪口检查和弹体移动忽略角色及附属物，弹体 BeginPlay 后重新应用忽略列表。真正的前方墙体仍能阻挡发射。

DA_Skill_01 的飞行外观改为独立金色发光核心，命中生成约 0.2 秒的金色脉冲闪光，取消遮挡镜头的旧火花与碎片。表现材质 M_PlayerParticleCore 位于 /Game/HPWH/Effects/PlayerParticle，技能数据的 ProjectileCoreMaterial 可单独调整；其他技能未配置该字段时继续使用原 Niagara／Cascade。原 75% 攻击力、2 秒 CD、12 米距离、1200 cm/s 速度与 0 法力不变。

实机命令 CC.PlayerParticleSmokeTest 覆盖默认、水平、俯视与第一人称的五种释放；CC.RealSkillsSmokeTest 验证真实命中伤害；CrashCourse.Skills.ProjectileMuzzleObstruction 保证近墙不会穿墙生成。加 -ParticleDiagnostics 可输出枪口阻挡与弹体碰撞明细。原始代码及技能备份：Saved/Backups/PlayerParticleFix_20261028。生成配置：Scripts/create_gold_particle_material.py，调用编辑器命令 CC.BuildGoldParticleFX。

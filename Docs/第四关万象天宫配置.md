## 进入与框架

区域 ID 为 `Heaven`，显示名称“万象天宫”，排列第四。按 N 打开行旅，选择“04 万象天宫”并确认；新角色和旧存档均默认解锁，无需先到访。沿用现有传送的角色就绪检查、加载进度、经验/背包/形态保存流程，不绕开这些检查。

地图的 World Settings → GameMode Override 为 `CC_AdventureGameMode`，GameInstance 也会识别区域并强制使用同一框架。出生点放在中央广场。角色、技能、背包、M 小地图、N 传送均由现有框架提供；倒下后仍按既有逻辑返回休憩之地。

传送界面扩展为四行，并将介绍和确认按钮下移；面板整体上移以避开右下角小地图。打包地图列表已加入新关卡。

## 材质与模型调整

本关从保存的网格样例实装，最多三层，保留59个手工格和自动补齐结果。不是进入游戏时重新随机；地图生成器 `Generate On Begin Play` 关闭，修改后应保存关卡。

本关独立资源都放在同名目录：

- `Materials/M_Heaven_0`～`M_Heaven_5`：本关材质，按现有调色板对应草地、石材、粉墙、木材、屋顶等，以材质实际颜色辨认。
- `Meshes/`：本关独立静态网格体及其材质槽，包含整栋房屋和分层模块。
- `Data/DA_HeavenTiles`：本关生成规则、模型与材质覆盖入口。

优先修改本目录中的材质和模型，避免影响插件里的演示关卡。完整模型替换使用模型自己的材质槽；如规则配置了 Materials 覆盖，则以规则为准。

## 修改布局

打开本关，选中“万象天宫 - 网格场景生成器”，进入 工具 → WFC 网格场景编辑器 → 读取选中生成器，再绘制和应用。重新生成会替换生成器所拥有的实例组件；不要只在这些组件上做需要长期保留的材质覆盖，应改上面的材质或规则资产。手工摆放的独立 Actor 不属于生成器，不会被它清除。

完整画板操作见[网格编辑器教程](../Plugins/SpiritWFC/Docs/网格场景编辑器完整教程.md)。安装脚本 `Scripts/WFC/install_wanxiang_heaven.py` 默认保留已存在的新地图，避免再次执行时覆盖美术调整。

当前保留的是街区占位模型和材质，供后续调整风格。本轮不添加敌人、任务、地牢门图或强制重新烘焙导航；实际游戏内传送和角色通行由开发者验收。

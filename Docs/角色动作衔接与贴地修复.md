# 角色动作衔接与贴地修复

2026-10-27。当前配置中模型Z=-90而角色胶囊体半高96，模型参考脚底约为本地Z=0，形成约6厘米间隙，另有角色移动组件保持的地面间距。切换形态原本不更新脚底偏移。

Locomotion根据当前模型参考包围盒、模型缩放/旋转、胶囊体高度和当前地面间距校准网格Z，切换形态立即刷新；跳跃时保留最后的地面间距，不把胶囊体强行贴地，不根据动画腿部动作反复上下拉模型；死亡布娃娃期间跳过。VisualGroundOffset可做单独美术微调，bAlignMeshToCapsule可关闭自动校准。

动画速度与播放倍率改为连续插值，Idle/Run使用12/4厘米每秒的进入/退出阈值防抖。落地保留0.24秒。既有状态图保留所有状态、动画与过渡规则，仅把切换时长按Idle/Run 0.24秒、Jump/Land进入0.10秒、Fall或落地退出0.18秒、Death进入0.12秒调整，并使用Cubic缓动。DefaultSlot持续更新下层运动姿态，攻击淡入/淡出调整为0.12/0.18秒。

这项校准解决模型基准高度，不等于双脚斜坡IK；动作本身抬脚、屈膝和腾空仍保留，复杂斜坡的逐脚贴合需要独立IK功能。

原代码及动画蓝图备份在Saved/Backups/CharacterContinuityFix_20261027。验证日志与运行结果以Saved中的CharacterContinuity相关文件为准。

适用工程：`CrashCourse.uproject`，Unreal Engine 5.6。配置日期：2026-10-24。

已生成 `/Game/UI/MuralMenu/WBP_MuralMenu`，已配置为测试地图的 Tab 入口，覆盖全 viewport。默认主页展示壁画与导航；背包、技能、交易、设置分别进入独立全屏功能页。本轮已完成编译、5 项核心自动测试、184 项菜单实测检查与 8 张分帧截图核对；菜单接口兼容、改键与实际粒子命中检查通过。

本次菜单使用桌面 `物魄奇谭2d资源` 中的正式 PNG。背景、按钮、立绘和竖版称号均按原始像素导入；透明边缘保留，不裁剪、不拉伸原图。`生成原稿备份`、说明文档、提示词 JSON 不作为游戏资源导入。

## 1. 打开与操作

测试地图保持 `/Game/HPWH/Maps/L_FlatTestArena`。Tab 打开菜单，Tab / Esc 关闭；关闭统一调用控制器接口，恢复游戏鼠标、镜头和移动输入。

主页左侧四个图文导航分别进入背包、技能、交易、设置；经验余额仅在背包页内显示，首页、技能、交易与设置页均不显示余额。功能页可返回主菜单；按最新要求已移除左下角返回按钮与按键提示，Tab / Esc 仍可关闭：

| 页面 | 操作与数据 |
|---|---|
| 背包 | 查看已存元素、当前经验与属性；选中元素后可“切换形态”或“进化”，显示当前/下一档数值与费用 |
| 技能 | 18项真实技能图标、四分类、数值简介、实际四槽和流派锁定；旧22模板保留 |
| 交易 | 使用经验购买永久属性等已配置商品 |
| 设置 | 双列金边面板，六行独立改键框、恢复默认、小地图显隐、存档状态与本地存读档 |

独立普攻继续为鼠标左键 / J；四技能默认 1、2、3、4；E 为交互。更改键位后，技能文字应读取控制器 `GetCombatKey`，不要在美术控件中写死数字。

器物交互**只把元素之力存入背包**，不当场变身。打开背包、选中已存元素后，“切换形态”才真正使用该力量；选择本身只浏览。可对当前使用的元素点击“进化”：初级到中级 100 经验，中级到高级 1000 经验。选中其他元素时先提示切换，不会仅因浏览就变身或升级别的路线。重复获取不重复添加，切换保留各自已购档位。

右侧立绘读取**当前实际形态与档位**，竖版称号在右上方。它们与菜单中的待购买路线或预览路线无关。变身或进化完成后再更新当前形态展示。

初始角色现在为初墨：白板生命 100、攻击 15 的 75%，即生命 75、攻击 11.25；初墨不可直接进化，不属于三档自然路线。自然路线使用白色交互方块解锁，绿色仍为青铜、黄色仍为陶塑。初始模型材质可在角色/形态资产上自行改黑，菜单立绘独立读取初墨图片。

菜单打开时世界继续运行，怪物可以移动与攻击。

## 2. 资产位置

```text
/Game/UI/MuralMenu/
  DA_MenuArt                      共用背景、Logo、四个导航及回退图片
  WBP_MuralMenu                    Widget Blueprint，父类 CC_MuralMenuWidget
  BP_MuralHUD                      HUD Blueprint，父类 CC_ProgressionHUD
  Textures/
    Menu/                         10 张背景、Logo、按钮
    Portraits/                    14 张角色壁画
    Titles/                       4 张竖版称号
```

测试入口配置如下：

| 配置位置 | 配置值 |
|---|---|
| `BP_ProgressionController → Crash / Menu → Progression Menu Class` | `WBP_MuralMenu` |
| `WBP_MuralMenu → Class Defaults → Menu → Art Data` | `DA_MenuArt` |
| `BP_ProgressionGameMode → HUD Class` | `BP_MuralHUD` |
| `BP_MuralHUD → Crash / UI → Show Debug Panel` | 关闭 |

`Show Debug Panel` 只控制原来的屏幕文字调试面板，不修改角色与怪物的世界血条。`ProgressionMenuClass` 清空后仍可使用原 C++ 文字菜单排查玩法接口。

当前 `WBP_MuralMenu` 的布局由父类 `CC_MuralMenuWidget` 的 C++ 构建，Designer 中不需要重复搭一套同名控件树。可以先改其 `Art Data` 和形态数据。若以后完全重做 Designer 页面，另建 UserWidget 子类，再把控制器的 `Progression Menu Class` 指向新类，并按 [UI 操作与 UMG 接入配置](UI操作与UMG接入配置.md) 接现有玩法接口。

## 4. 每档形态绑定对应立绘

在 Content Browser 打开对应 `DA_Form_*`，展开 `Stages`，每档都有 Menu 分组：

- `Menu Portrait`：该档立绘的 Texture2D 软引用。

## 5. C++ 父类与蓝图接口

`CC_MenuArtData` 是菜单共用美术数据的 DataAsset 父类，维护背景、Logo、导航与缺图回退；不存经验、属性、进化等级。

`CC_MuralMenuWidget` 是当前壁画菜单的 UserWidget 父类。它通过玩家的 Progression / Skills 组件、控制器接口执行交易、装备、键位与存读档，UI 本身不直接扣经验或修改战斗属性。

| 蓝图接口 | 用途 |
|---|---|
| `ShowPage(ECC_MuralMenuPage)` | 切换 Overview 主页、Inventory 背包、Skills 技能、Trade 交易、Settings 设置 |
| `SelectSkillSlot(Index)` | 选择四技能槽，Index 为 0～3 |
| `GetDisplayedPortraitTexture()` | 读取菜单当前正在显示的立绘 |
| `GetDisplayedTitleTexture()` | 读取当前称号图 |
| `GetDisplayedFormId()` | 读取当前实际形态 ID，便于调试 |
| `GetDisplayedTier()` | 读取当前实际档位，0 为初级 |
| `GetMenuPage()` | 读取当前页面 |

显示刷新依据 `Progression.GetActiveForm() + CurrentTier` 的 Stage 引用；`CurrentForm=nullptr` 时当前是 `NativeForm` 初墨。自然 `DA_Form_Native` 虽然名称带 Native，实际已进入需要交互解锁的 `ArtifactForms`。`SwitchForm(nullptr)` 是回初墨，切自然必须传自然 Form 资产。数值与 22 项技能简介继续从实际属性、技能定义计算，装备成功通知、购买结果与菜单显隐接口保留。详细类说明见 [CC_MenuArtData](CPPClasses/UCC_MenuArtData.md) 和 [CC_MuralMenuWidget](CPPClasses/UCC_MuralMenuWidget.md)。

## 6. 图片导入规范与替换

导入脚本：`Scripts/import_mural_menu_assets.py`。共 28 张正式图片：10 张菜单、14 张角色壁画、4 张称号。

| 纹理设置 | 配置 |
|---|---|
| Compression Settings | UserInterface2D (RGBA8) |
| LOD Group | UI |
| Mip Gen Settings | NoMipmaps |
| sRGB | 开启 |
| Compress Without Alpha | 关闭 |
| Never Stream | 开启 |
| Maximum Texture Size | 0，保留源图最大分辨率 |

立绘源图均为 1024×1536；导航图片为 836×260；背景为 1672×941；Logo 为 1962×801。初墨 / 自然 / 陶塑称号为 724×2172，青铜称号为 733×2144。界面应按图片实际宽高比等比适配，不能把所有竖版称号强行拉成同一比例。

替换图片有两种方式：

1. 只替换某个现有纹理：在 Content Browser 对目标纹理使用 Reimport / Reimport With New File，保留资产名和引用；核对 UI 压缩与透明通道。
2. 新增图片：导入同一类别文件夹，再在 `DA_MenuArt` 或某个 Stage 的 Menu 字段改引用。

不要把 `DA_MenuArt` 的回退图片当成每个形态的正式图片入口；每档图在各形态 Stage 配置。

## 左下角拾取提示（2026-10-24）

当前 `BP_MuralHUD` 的 `PickupPromptTexture` 已指定 `/Game/UI/MuralMenu/Textures/Interaction/T_Prompt_Pickup`。使用提供的 E 拾取原图，进入有效交互范围自动显示在左下角，离开范围、被墙遮挡、打开菜单或角色死亡时隐藏；已消耗经验包不再触发。提示不受 `bShowDebugPanel` 开关影响，经验余额仍只在背包显示。

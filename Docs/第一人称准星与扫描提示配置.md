# 第一人称准星与扫描提示

按 T 切到第一人称后显示中心细线准星，默认自动扫描 6 米内准星指向的对象，每秒查询 10 次。发现有效对象后准星转为暗金色，下方显示名称、简短说明、距离；满足原有交互距离时才显示实际交互键。第三人称、角色死亡、完整菜单或传送状态下不显示准星与扫描卡片。鼠标右键战技面板不会暂停扫描。

## 提示文字储存在哪里

内容浏览器打开 **Content / UI / Scan**（资源路径 `/Game/UI/Scan`）：

| 资源 | 用途 |
| --- | --- |
| DA_ScanCatalog | 默认对象类型和提示资产的对应规则，顺序靠前的匹配优先 |
| DA_Scan_Platform | 浮空石台的默认名称、说明、重组提示 |
| DA_Scan_Artifact | 物魄信物的默认说明 |
| DA_Scan_Experience | 经验灵物的默认说明 |
| DA_Scan_Enemy | 敌对物魄的默认说明 |
| DA_Scan_Example | 普通场景物体的可复制示例 |

双击提示资产，编辑 Display Name、Description、Action Text 和 Max Distance。Description 建议控制在两行短句以内。Max Distance 和扫描组件全局 Scan Distance 共同限制距离，默认都是 600 厘米。静态文案随项目资产保存，不写在角色代码、UI 蓝图或玩家存档里。

## 给一个普通物体添加提示

1. 复制 DA_Scan_Example，起一个对应物体的资源名并填写文案。
2. 选中关卡物体，或打开它的 Actor 蓝图，添加 **扫描目标 / Scan Target（CC_ScanTargetComponent）**。
3. 在组件 Info 选择刚才的提示资产，保持 Enabled。保存关卡或蓝图。
4. 物体的可见网格需要开启查询碰撞，Visibility 通道设为 Block；然后在第一人称中对准它。

组件绑定优先于 Catalog 默认规则，取消组件 Enabled 可单独关闭该物体的扫描。只绑定说明不会凭空新增 E 交互：普通物体只显示信息；浮台、经验灵物、信物会复用已有的真实交互检查。敌人通过 Pawn 查询补充识别，墙体始终优先遮挡；不会隔墙扫描。

新增一整类物体时，也可以在 DA_ScanCatalog 的 Rules 添加 Actor Class 或 Component Class 与提示资产的对应关系；两者同时指定时需同时满足。不要添加两个条件都为空的规则。

## 交互与实现

第一人称 E 使用与准星相同的射线目标，避免瞄准甲却交互旁边的乙；第三人称保留原近邻交互。扫描只读取信息，不消耗资源、不触发交互、不永久记录“已发现”。真正交互继续由服务器验证距离、状态和视线。

扫描实现：CC_PlayerScanComponent；提示组件与数据：CC_ScanData.h；准星和信息卡：CC_FirstPersonScanWidget。玩家控制器持有 Scanner，HUD 创建 FirstPersonScanHUD。UI/Scan 已加入打包必包含目录。

初始化脚本 Scripts/configure_scan_hud.py 再次执行时保留现有文案和规则。显式实机验证命令 CC.FirstPersonScanSmokeTest；报告保存在对应测试 UserDir/Saved/ScanSmoke.json，截图位于 Saved/Screenshots/Scan。修改前备份在 Saved/Backups/FirstPersonScan_20261028。


### 最终规则：第一人称即观察模式

只有第一人称观察模式显示准星、扫描信息和 E 交互提示。按 T 返回第三人称后立即隐藏这些内容，即使旁边有可交互对象，也不显示提示；旧图片提示和调试准星同样受此限制。第一人称中对准范围内对象显示信息，符合真实交互距离时显示对应按键。菜单、死亡、传送时隐藏。此次只调整提示的可见性，原有第三人称 E 交互行为保持原样。提示文案仍保存在 UI/Scan 数据资产中。


### 菜单键避让编辑器测试退出键

鼠标右键展开／收起战技面板，Tab 打开／关闭完整菜单。键位录入时按 Tab 取消当前录入，行旅面板按 Tab 转入完整菜单。T 切换观察模式，疾跑使用长按左右 Shift。右键和 Tab 保留给界面，Shift 不再触发菜单。游戏不将 Esc 绑定到菜单，保留编辑器测试的原生退出操作。


### 万象天宫 E 的最终含义

万象天宫 E 改为整个 WFC 大场景的随机重组，直接切换道路与房屋布局，不再重排九块石板。观察模式文案由 UI/Scan/DA_Scan_HeavenScene 配置；第三人称隐藏提示的规则保留。具体行为与角色安全安置见 Docs/万象天宫整场景随机重组.md。

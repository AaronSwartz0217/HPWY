# HPWH 弹体、四合院与移动触控

- 共用 HPWH 弹体新增六颗渐缩的实例化粒子拖尾。玩家／友方为暖金，敌对为蓝；只影响显示，不改变子弹伤害、寿命与命中判定。
- 四合院静态网格使用 Complex as Simple，开启 LOD0 区段碰撞。附带旧墙仅用于导入模型碰撞不可用时的回退。解谜仍在开启和限时内，由存活的普通敌人进入 320 cm 内触发；徘徊者不计入。
- 三种群系内的积木，每块独立按原尺寸乘上 0.7 至 1.0；叠层按实际高度堆叠，保持原布局随机序列。
- 触控使用独立手指 ID；释放时复位。右侧攻击键可跟手拖到自身半径的 45%，保留交互优先及原射击行为。原方向检查通过；多指操作需 Android/iOS 真机验收。
- 11 个 SFX 和 3 首背景音乐已在 UE 加载核对，音频目录显式纳入打包。双方射击沿用 Attack 音源，由各自的音量、音高和播放位置区分；没有制作新音频。
四合院物理测试：原 0.28 缩放阻断 320 cm 判定范围；改为 0.21 后，胶囊扫掠确认墙可阻挡，180 条接近路线中有 94 条能到达 315 cm。Editor Development、CourtyardMesh 和 TouchInput 均通过。

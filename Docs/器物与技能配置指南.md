# 器物与技能配置指南

## 当前版本

更新日期：2026-10-24。完整交付状态见 [总说明](完整功能更新与配置说明.md)。初始为初墨，75生命／11.25攻击，不可直接进化。白/绿/黄器物分别将自然/青铜/陶塑存入背包，三条开放路线各有初、中、高三级。神秘、墨化保留未开放。经验共用，各路线档位、永久属性和技能等级商品分别记录。

当前是可试玩原型。自然、青铜、陶塑三路线九档形态已有模型、专属动画、攻击姿势与占位特效，投射物带 Niagara；22项执行技能模板保留；新18项图标通过ExecutableSkill接实际机制，执行目录合计39项。Tab壁画菜单提供背包/切换/进化、真实技能装备、交易和设置，器物与黑色经验包仍使用方块占位。

## 直接试运行

打开 `/Game/HPWH/Maps/L_FlatTestArena`，点击 Play。这是新的默认启动地图，包含 120 米平地、自然白色器物、青铜绿色器物、陶塑黄色器物、黑色经验包、初墨玩家/NPC及全屏壁画菜单，另两种器物暂时隐藏。地图使用独立的 BP_ProgressionGameMode，原来的 OverRide 与旧 L_HPWH 均保留。

| 按键 | 功能 |
|---|---|
| J / 鼠标左键 | 独立普攻，不占四技能槽 |
| 1、2、3、4 | 当前四个技能 |
| E | 面向附近器物或黑色经验包交互，服务器验证距离及视线 |
| Tab | 打开背包/进化菜单，Tab/Esc 关闭 |
| F1（可选原型调试绑定） | 购买当前路线下一档；初墨不可进化 |
| F2（可选原型调试绑定） | 返回初墨 |
| F3～F6（可选原型调试绑定） | 切换四种已解锁的器物形态 |
| F7～F12（可选原型调试绑定） | 依次购买六种示例升级商品 |

F1～F12仅在控制器Show Progression Panel启用时绑定，是可选原型调试入口；默认操作请使用壁画菜单。隐藏0/9另见[开发隐藏按键](开发隐藏按键.md)。

示例费用：中级 100、高级 1000；属性商品每级价格为 25、50、100、150、250。示例怪物低/中/高级/精英分别奖励10/40/200/500经验，实际接触入账；单次最多128颗分摊总额，黑色包 E 交互产生 50 颗，每颗接触领取者后 +1 经验。技能法力消耗与冷却可在资产中调整；经验不提供客户端自增入口。

## 场景中的器物如何标记

推荐使用“组件 + 数据资产引用”。不要求所有场景物体改继承同一个器物父蓝图，也不靠字符串标签查表来决定形态。

### 方式 A：现有物体蓝图挂组件

1. 打开物体的 Actor 蓝图，添加 `CC Artifact Component`。
2. 在组件的 `Form` 里指定 `/Game/HPWH/Forms/DA_Form_Artifact_01` 至 `04` 中的一份配置。
3. 设置交互距离，默认 250；开启 `Enabled`。
4. 物体模型的碰撞需要响应 Visibility 射线；联网时 Actor 开启 Replicates。
5. 确认该形态也在玩家状态的 Progression → Artifact Forms 白名单中。
6. 需要交互反馈时绑定组件的 `On Interacted` 事件。它在服务器成功交互后触发；联网表现应自行复制或广播。

多个物体可以引用同一个形态配置，例如同类型的不同器物都解锁同一种变身。首次交互只解锁并存入背包，之后从背包显式切换形态；重复获取不重复添加；默认不销毁器物，以便多人各自解锁。

### 方式 B：直接使用器物蓝图

把 `/Game/HPWH/Blueprints/BP_Artifact_01` 至 `04` 拖入场景。它们继承 C++ `CC_FormArtifact`，已经包含模型组件和交互组件，替换模型即可。

Actor Tag `SpecialArtifact` 仅用于查找和分类。真正的交互能力来自组件，目标形态来自 `Form` 引用。给普通物体只添加标签不会自动变身。

## 初始角色与力量路线配置

打开 `/Game/HPWH/Forms`：

- `DA_Form_InitialInk`：初墨，Progression.NativeForm指向它，始终可用且不可进化。
- `DA_Form_Native`：自然路线，保留Native稳定ID，通过白色器物解锁。
- `DA_Form_Artifact_01`～`04`：青铜、陶塑及两条未开放预留；只有Available=true的目录项允许获取/使用。

三条开放路线的Stages为三项，索引0、1、2对应初级、中级、高级；初墨为单独初始配置。各阶段可修改费用、最大生命、最大法力、攻击、防御、移速、技能组、模型与动画类。修改显示名称不影响存档；稳定的 Form Id 不要随意更改。

在 `BP_ProgressionPlayerState` 的 Progression 组件上指定 Native Form=InitialInk，Artifact Forms中包含自然、青铜、陶塑及预留目录，另配Upgrade Catalog。当前代码支持扩展形态数量。

## 22个执行技能与四槽组合

技能位于 `/Game/HPWH/Skills/DA_Skill_01`～`22`（20模板＋保留交替拳击/短时疾跑）。新美术页18项已接真实配装与执行机制，详见[技能界面美术配置](技能界面美术配置.md)。当前编号 01 是粒子远程，05 是近战，其余配置见[数值与技能面板配置](./数值与技能面板配置.md)。

- `Display Name`：你后续填写的名称。
- `Skill Id`：稳定 ID，用于等级商品与存档，保持现有SkillId，不用界面设计ID覆盖战斗ID。
- `Behavior`：技能行为。
- `Power / Power Per Level`：基础强度与每级增加量。
- `Mana Cost / Cooldown`：法力消耗与冷却。
- `Range / Radius / Angle`：射程、范围与扇形角度。
- `Duration / Interval / Count`：持续时长、跳伤间隔、连击／投射物数量。
- `Ability Class`：留空使用内置执行器，指定自定义 GA 时需自行遵循消耗、冷却与结束事件约定。

在 `/Game/HPWH/Loadouts` 里配置四个 Slots，每槽填写技能及基础等级。要求四槽有效且 Skill Id 不重复。不同档位可以换技能，也可以使用相同技能、提高等级。

`BP_ProgressionEnemy` 的 Skills → Default Loadout 使用相同配置结构。示例 AI 按距离、可用性与随机起点选择四槽技能；完整行为树、优先级权重和团队阵营系统尚未扩展。当前以角色 Actor Tag `Player` 区分玩家阵营和怪物阵营。

## 经验与购买

死亡布娃娃、敌人十秒清理与经验粒子/黑色包的配置见[专门指南](./死亡布娃娃与经验粒子配置.md)。经验归属击杀者的 PlayerState，产生时不预入账；不要在死亡或包蓝图另接 AddExperience。

商品位于 `/Game/HPWH/Upgrades`。支持最大生命、最大法力、攻击、防御、移速、指定技能等级。Prices 数组长度就是最高可购买等级，每项为进入下一等级的价格。

属性购买默认全形态生效；技能等级商品通过 Skill Id 指定目标，每次购买加一级。`Bonus Per Level` 用于属性商品；技能等级商品固定每次加一级。

攻击数值现表示实际攻击力，白板为 15；按攻击力缩放的技能先乘自身系数，再结算目标防御。防御结算系数为 `100 / (100 + 防御)`。护盾先吸收伤害；护盾再次释放时替换旧护盾，独立到期计时，不累加。临时攻击、防御、移速效果由 GAS 到期移除。

变身与进化保持生命和法力百分比，永久属性按当前形态基础值重新计算，不通过反复切换累加。冷却以四槽标签保留在 ASC 上，切换形态不会清除对应槽冷却。

新技能使用 IncomingDamage 统一结算。旧技能蓝图如果仍直接对 Health 施加负数，保留原有行为和击杀奖励，但不会自动获得新的攻击／防御／护盾结算；迁移时应改用 CC_DamageEffect 或内置技能执行器。

## 蓝图接口与保存

从玩家 PlayerState 获取 Progression 组件：

- `Interact(Actor)`：交互请求。
- `Switch Form(Form)`：切换已解锁形态；传空恢复初墨；切自然需传自然资产。
- `Evolve()`：购买当前形态的下一阶段。
- `Purchase(Upgrade)`：购买目录中的商品。
- `Get Evolution Cost()`：查询下一档费用，-1 表示不可用。
- `On Changed / On Purchase Finished`：更新正式 UI 与显示失败原因。
- `Add Experience(Amount)`：仅可信服务器逻辑可发放经验，无客户端增发 RPC。
- `Save Progress / Load Progress`：单机手动保存和载入，默认槽 SpiritTales；设置页已接手动保存/读取，未接自动保存。

保存内容为经验、初始ID、力量解锁／档位、当前形态、商品等级和实际手动四槽。键位单独自动保存在Controls槽。不保存临时效果、生命／法力快照或场景器物状态。不提供联网账号存档；联网时禁止使用本地 SaveGame 导入钱包。

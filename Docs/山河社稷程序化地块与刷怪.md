# 山河社稷程序化地块与刷怪

地图仍为 `/Game/HPWH/Maps/L_FlatTestArena`，行旅中显示“山河社稷”。仅在此地图启用地块生成器和刷怪管理器。

## 九块地形窗口

每块边长80米，以玩家所在块为中心，保留周围八块，共九块。每0.25秒检查玩家位置；跨边界先卸载离开范围的块，再生成进入范围的块，重合部分复用，远距离传送也只保留九块。

起点块为 `(0,0)`，覆盖世界 X、Y 各 `[-4000,4000)` 厘米；相邻块中心相距8000厘米。负坐标向下取整。默认种子29717，地形由种子和坐标确定，返回旧坐标会复现相同布局。

当前地形由平面地块、实例化竹丛与岩石组成，十字小路连续相接；起点约19米内留空。岩石有碰撞并参与导航，竹秆与叶片为轻量装饰。原测试底板保留在编辑器，运行时隐藏、关闭碰撞；新地块承担真实地面碰撞。导航范围随窗口移动并异步重建。

选中“山河社稷_九宫地块生成器”可调整：

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| ChunkSize | 8000厘米 | 每块边长 |
| WorldSeed | 29717 | 地形种子，修改后重新运行 |
| GrovesPerChunk | 10 | 每块尝试布置的竹丛数，每丛5根 |
| RocksPerChunk | 12 | 每块尝试布置的岩石数 |
| GroundMaterials | 三种草地色调 | 地面与小路材质 |

窗口以首位玩家为中心，当前按单人探索使用；尚无地形挖掘、体素编辑、地表修改存档或多人分散探索规则。

## 动态刷怪

采用玩家周围距离环、成组生成、数量预算和远处回收，不按昼夜或灯光亮度判断。

| 规则 | 默认值 |
| --- | --- |
| 首次尝试 | 进图4秒后 |
| 检查间隔 | 6秒 |
| 每次补充 | 1～3只，后续成员尝试在首只附近成群 |
| 生成距离 | 离每位玩家至少18米，离中心玩家最多36米 |
| 出生点保护 | PlayerStart周围18米 |
| 附近上限 | 42米内12只存活巡逻怪 |
| 动态怪全局上限 | 18只 |
| 最小生成间距 | 3.5米 |
| 软回收 | 离所有玩家45米外持续30秒，且不在视野内 |
| 硬回收 | 离所有玩家65米外 |

生成位置必须有可走地面、胶囊净空和可达导航路径，并属于已加载地块。正看着的无遮挡区域不突然生成。地面 Actor 添加 `NoAmbientSpawn` 可禁止在该物体上生成。

运行时由刷怪器替代旧测试地图的巡逻怪与精英，编辑器原摆放保留，木桩保留。固定巡逻敌人可加 `CC.KeepPlacedEnemy`，其数量仍计入附近密度。回收不调用死亡或经验结算；正常击杀保留经验和尸体清理。地块卸载会立即回收其中的动态怪。

## 坐标与强度

出生地块的圈数为 `max(abs(X),abs(Y))`。强度在出生时确定，追击跨界不会突然升级或回复生命。

| 坐标圈数 | 敌人组成 |
| --- | --- |
| 0～1圈 | 低级竹路人 |
| 2～3圈 | 竹路人与竹节人，向中级倾斜 |
| 第4圈及更远 | 竹节人与竹拳击手，高级同时最多3只 |

超过第4圈后，每额外一圈按基础档案增加12%生命、4%攻击、10%经验奖励，分别封顶为基础值的3倍、1.75倍、2倍。第5圈即1.12倍生命、1.04倍攻击、1.1倍经验；奖励取整数。回到起点后新刷出的怪重新使用低级档案。

“山河社稷_刷怪管理器”调整密度和距离；竹怪蓝图位于 `/Game/HPWH/Spawning`，分别引用自然三档模型、动画与战斗档案。当前只有地形固定复现，怪物仍动态刷新，不持久化单只怪的位置。

## 配置与检查

脚本 `Scripts/apply_black_ink_and_spawning.py` 更新黑色初墨、竹怪配置和地图。日常调参直接改地图实例或蓝图，重跑脚本会恢复脚本内配置。

# 开发隐藏按键

适用：2026-10-29，CrashCourse 编辑器与 Development 构建，本机 standalone / 单机 PIE。

这两个键不显示在玩家界面、技能目录、设置列表或 HUD 中，不是额外占用四槽的技能。Shipping 和 Test 构建不绑定，网络会话拒绝执行。数字键使用键盘上方的 0、9，不是小键盘。

| 按键 | 效果 |
|---|---|
| 9 | 完整测试模式：解锁所有已完成路线、技能与最高档属性；远程商店与全部地区可用；所有目录物品各999，包括五种药水和两种传送卷轴；经验、铜币各1,000,000；恢复生命并清除当前冷却 |
| 0 | 初始化当前测试进度：初始墨人、默认四技能、满血；清空成长、铜币经验、物品、商店权限、斑斓形态与地区访问记录；取消凝聚中的传送并清除冷却 |

9 保持当前选择的形态；0 恢复初始墨人。神秘与墨化仍遵守资产 Available=false 的暂不开启配置，不修改共享 DataAsset。

当前目录39项，包含原22模板与17个新定义；9后开放三个流派，18项正式图标可真实配装，旧模板可由原接口/文字回退页配置。仍同时携带四技能，第5栏继续用于道具。技能等级由已有升级商品决定，没有商品的技能沿用其配置等级。

反复按9将物品补回999，不重复堆叠属性或库存条目；反复按0保持初始进度。两键在开发构建中为保留按键，不能被设置页占用。菜单打开或死亡后仍可操作，菜单数值与立绘通过原状态通知刷新。

9不再清零成长。保持当前位置与战斗键位，不重建地图或重生全部怪物。集齐三力对应的斑斓描边与彩虹血条同时开启，Q仍可关闭描边。传送仍需8秒凝聚、正常消耗卷轴，之后继续遵守30秒传送冷却；再次按9会清除当前冷却。

测试库存使用独立999上限标记，界面显示999/999，普通模式仍遵守商品的99上限。该标记和库存随已有跨图快照恢复；正常使用会扣数量，再按9补满。0调用 `ApplyDeveloperPreset(false)` 清零当前进度。初始化保持当前地图、位置和键位，不重建场景中的怪物，不删除磁盘上的已有存档。

两键都不自动保存、不删除现有本地存档、不提交后端。若随后手动点击保存，当前测试状态才会写入本地进度。

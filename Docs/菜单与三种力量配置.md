# 菜单、三种力量与 NPC 美术配置

更新日期：2026-10-24。本文保留早期素材配置与验证记录；当前总入口见 [完整说明](完整功能更新与配置说明.md)，菜单美术见 [壁画菜单资源配置](壁画菜单资源配置.md)。

当前规则：低级/中级/高级/精英奖励10/40/200/500经验；初级购买中级花费 100，中级购买高级花费 1000，总花费 1100。经验是共享货币，购买会扣除。

初始为初墨（75生命／11.25攻击，不可直接进化）。白色器物解锁自然之力。绿色器物解锁青铜之力，黄色器物解锁陶塑之力。神秘之力和墨化之力的定义仍保留稳定 ID，但 Available=false，菜单／提示隐藏，交互、快捷键切换和旧存档选中均被服务器拒绝。场景对应后两个方块隐藏并关闭碰撞。

三条路线的初／中／高级已分别配置不同模型，见 [三条力量进化路线](三条力量进化路线.md)。MeshScale 将模型显示尺寸调整到约 180 cm；切回自然使用自然路线当前档位的竹人模型。

- 左键或 J：独立普攻；1～4：四技能。
- Tab：打开全屏壁画菜单；交互只存力量，背包查看经验、选择力量、切换形态并购买进化。新技能页18项已接真实配装和机制，未获取力量时不能使用其流派技能。
- Tab／Esc：关闭菜单，返回游戏；左下不再显示返回提示。
- 菜单打开期间不接受角色操作；怪物和世界继续运行。

关键配置位置：

| 内容 | 资源／字段 |
|---|---|
| 名称、是否开放、三档费用 | HPWH/Forms/DA_Form_*：DisplayName、Available、Stages.Cost |
| 变身模型与缩放 | 同上 Stages.Mesh／MeshScale／AnimClass |
| 怪物奖励 | 共享CombatBalance.Profiles.ExperienceReward=10/40/200/500 |
| 模型动画对应 | HPWH/Locomotion/DA_NPCLocomotion |
| 跑步／待机动画 | HPWH/Locomotion/Animations/A_角色名_Run／Idle |
| NPC 原型父类 | CC_PatrolEnemyCharacter，保留四技能与范围巡逻 |

测试场 4 个巡逻敌人与 6 个靶子已使用青铜、草竹模型。靶子保持被动，巡逻敌人按实际移速播放跑步，停止后播放待机。后续已补模型专用六状态ABP、跳跃/落地/死亡和三种攻击姿势；细化受击、连招、IK及正式特效音效仍需继续。另有两类精英。

资源命名范围仅 `/Game/SOURCE`，12 套角色共 48 个资源：SK_骨骼网格体、SKEL_骨架、PHYS_物理资产、M_材质。未改原始贴图名或移动分类文件夹。对应关系见 [资源重命名清单](资源重命名清单.json)，原文件备份位于 Saved/SourceNamingBackup。保留旧路径重定向以维护旧引用，不要手动删除重定向文件。

脚本顺序：先配置三种力量，再生成重定向动画，执行 `Scripts/fix_retarget_import_scale.py` 修复这批模型的根骨缩放／高度，最后 configure_npc_art.py。旧 build_flat_test_arena.py 会重建原型关卡，不能用它覆盖当前配置后的地图；需要重建时，最后补跑 setup_patrol_enemy.py 和上述配置脚本。

根骨修正只作用于生成的动画：导入骨架根骨缩放约为 100，默认批量导出会写成 1，同时将 Hips 根位置归零。修正脚本恢复参考缩放和高度，避免模型缩小或落到地面下；同一动画重复运行不会再次放大。后续更换其他来源模型时应先检查根骨规范，不能把该补偿当作通用导入规则。

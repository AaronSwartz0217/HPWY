# 元素信物与能力球配置

更新：2026-10-24。能力球代码已随当前工程通过UE5.6 CrashCourseEditor / Win64 / Development编译；未运行游戏测试，联调由前端进行。

## 交互流程

1. 靠近元素方块，显示原有左下角E提示。
2. 按E，服务端复核距离、遮挡、存活及形态目录；方块立即隐藏并关闭碰撞。
3. 方块顶部弹出一颗能力球，物理散射约0.45秒后，沿用经验球的加速吸附。
4. 接触发起交互角色的胶囊后，同时将力量存入背包、增加50经验，球消失。
5. 在背包选择“切换形态”才变身。尚未吸收时，对应流派技能继续锁定。

每个方块当前会话只释放一次，连续E不会重复出球。另一个同流派信物仍给50经验，已有力量不重复入包、不重置进化档位。未领取球超时销毁后原方块恢复；角色死亡期间不向尸体发奖，最长等待60秒。

世界信物消耗状态与未领取能力球尚未写入进度存档，重新进入关卡会重建，退出不补发未领取奖励。

## 配色

| 力量 | 稳定FormId | 现有蓝图 | 主色 / 辅色 |
|---|---|---|---|
| 青铜 | Artifact_01 | BP_Artifact_01 | 蓝色 / 金黄色 |
| 陶塑 | Artifact_02 | BP_Artifact_02 | 黄棕色 / 土黄色 |
| 自然 | Native | BP_Artifact_Nature | 绿色 / 浅绿色 |

蓝图仍在`/Game/HPWH/Blueprints`。编译后现有ACC_FormArtifact实例在构造和BeginPlay调用RefreshPowerPresentation：方块使用主色，ColorBand使用辅色；球体使用同样颜色，辅色小球围绕主球运动。无需重摆方块或重导模型。

复用`/Game/HPWH/Materials/M_TestTint`的Tint参数与引擎Sphere/Cube，直接沿用经验球移动和领取逻辑。独立TextRenderActor里的WHITE/GREEN/YELLOW旧文字不是逻辑依据，美术可改字或删除。

Artifact.PowerOrbSystem可选配Niagara装饰，装饰颜色需自行配置。核心彩色球体不依赖新Niagara资产；默认橙色经验系统不会自动读取PowerColor。

## 参数和接口

- UCC_ArtifactComponent.Form：完整力量资产，必须注册到Progression.ArtifactForms。
- ExperienceReward：默认50，表示这一颗球的经验价值，而非球数量。
- bUseFormPalette：默认true，使用上表配色；设false后读PowerColor/AccentColor。
- GetPowerColors：供方块、球和后续UI查询实际主辅色。
- bConsumed：复制状态。释放后隐藏并禁止交互，未领取球销毁后回退。
- OnInteracted：表示球已成功释放，此刻尚未入包和增加经验。
- ACC_FormArtifact.RefreshPowerPresentation：可由蓝图或编辑器Details刷新。TintMaterial可换成带Tint向量参数的材质；现有三个蓝图父类不变。
- ACC_FormPowerOrb：继承经验球的Scattering/Seeking/Collected、领取者与胶囊接触校验。RewardForm、Recipient、ExperienceValue在服务端延迟生成时设置；颜色与移动复制。GrantReward通过Progression内部CollectArtifactPower原子提交力量和经验；失败则保留球等待有效接触。

挂到自定义Actor的Artifact组件同样使用释放/隐藏逻辑，但自动重着色由ACC_FormArtifact便捷父类执行。其他Actor可自行读取GetPowerColors设置材质。普通怪物经验球和黑色50经验包保留原发放逻辑。

## UI和交接

键位仍为E，控制器继续RequestInteraction。OnPurchaseFinished.Success在此仅确认释放成功；真正入包和钱包变化监听Progression.OnChanged，球接触后再刷新背包与流派解锁。

前端在平地场景检查三种配色、E后隐藏、吸收前余额不变、接触后+50并入包、重复E去重、背包切换与立绘联动。当前编译已通过，尚无本流程运行通过记录；历史自动化中“按E立即入包”的断言需按接触时结算更新后再使用。

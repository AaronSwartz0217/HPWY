# 从零配置与接入步骤

更新日期：2026-10-24。本文说明接入接口；完整状态与脚本覆盖边界见[总说明](完整功能更新与配置说明.md)。当前闭环：初墨 → 器物交互只存力量 → 背包切换形态 → 新四技能与属性 → 击杀吸附经验 → 花经验进化。初墨75生命/11.25攻击，不可进化；自然/青铜/陶塑三条开放路线各三档，神秘/墨化预留。

## 1. 先运行已有样例

1. 使用 UE 5.6 打开 CrashCourse.uproject。
2. 工程默认打开 `/Game/UI/MainMenu/Maps/L_MainMenu`，Play后显示首页，开始游戏进入休憩之地。测试场可用N选择山河社稷，或在编辑器手动打开 `/Game/HPWH/Maps/L_FlatTestArena`；旧 L_HPWH 保留。
3. 首页运行时使用 `CC_MainMenuGameMode`，三个游戏地区由 `CC_AdventureGameInstance` 统一使用 `CC_AdventureGameMode`；关卡World Settings保存的旧模式会被覆盖。
4. Play 后用 WASD/鼠标移动视角、空格跳跃，J 或鼠标左键普攻，数字键 1～4 对应四技能，再靠近器物面向它按 E。
5. 低/中/高级/精英分别掉落10/40/200/500经验，最多128颗分摊总额，黑色方块E发出50颗，实际吸附才入账。Tab打开壁画菜单，背包查看经验、选中力量并切换，再为当前路线购买下一档（中级100，高级1000）。自然白色、青铜绿色、陶塑黄色；Tab/Esc退出。新技能页18项已接真实装备与机制；旧22模板保留，完整目录39项。

当前GameMode.HUDClass使用BP_MuralHUD（父类CC_ProgressionHUD），默认关闭调试面板并配置拾取提示图；控制器ProgressionMenuClass指定WBP_MuralMenu。不要换回裸HUD覆盖美术配置。J/1～4/E正常操作不依赖原型F键调试开关。

示例美术和特效可替换。玩家九个形态和十个 NPC 已配置模型专属 ABP、跳跃/下落/落地与攻击姿势，投射物附着 Niagara。配置位置及故障排查见 [动画配置指南](./动画状态机与技能表现配置.md)。

## 2. 接到自己的关卡

建议复制 `/Game/HPWH` 下需要的样例蓝图／资产到正式目录后配置，避免后来重跑生成脚本重置自己的内容。

在自用 GameMode 蓝图 Class Defaults 配置：

| 字段 | 示例值 | 对应 C++ 基类 |
|---|---|---|
| Default Pawn Class | BP_ProgressionCharacter | ACC_PlayerCharacter |
| Player Controller Class | BP_ProgressionController | ACC_PlayerController |
| Player State Class | BP_ProgressionPlayerState | ACC_PlayerState |
| HUD Class | BP_MuralHUD（当前美术/拾取提示配置） | ACC_ProgressionHUD |

再到关卡 World Settings 指定这个 GameMode，放置 PlayerStart。不要额外放一个 Auto Possess Player 的旧角色来代替 GameMode 生成的角色，否则可能误以为新配置没有生效。

已有蓝图如果继承了正确 C++ 父类，不需要为了接入重复改父类；补字段和引用即可。改变父类前应确认现有继承组件、事件图与变量兼容。

## 3. 玩家角色和初始属性

打开玩家角色蓝图：

1. Mesh 设置可用骨骼网格和动画蓝图。
2. Class Defaults → Initialize Attributes Effect 指定 `CC_InitialAttributesEffect`，或自己已经填好数值的初始化 GE。旧教程 GE 仅有资源名不代表内部已填数值。
3. Reset Attributes Effect 指定需要的重置 GE。
4. 初始化 GE 至少提供有效的最大生命、生命、最大法力、法力；最大生命大于零。
5. 保留继承来的 Skills 组件，不要再添加第二个。
6. Startup Abilities 放公共受击／死亡等能力；不要把新四槽技能再重复填入。

玩家 ASC 在 PlayerState，不在玩家 Pawn。只更换 Pawn 而没使用 CC_PlayerState 派生类，会让 GAS 初始化失败。

## 4. 先配一组初始技能

1. 打开 `DA_Skill_01`～`22`，先修改 Display Name，保留稳定 Skill Id。
2. 选出四个技能，比如近战、投射物、位移、治疗。
3. 复制一个 `CC_SkillLoadout` Data Asset，将四个技能放到 Slots[0]～[3]，Level 先设 1。
4. Skill 不为空，SkillId 不为空且四槽之间不重复。
5. 原生形态 Stages[0].Loadout 引用这份技能组。

技能基准公式为 `Power + (有效等级 - 1) × PowerPerLevel`。并非所有参数对所有行为都有作用，例如 Count 在散射中是弹数，在穿透中是命中上限，在连击中是段数。

普通配置不必为 20 个技能分别新建 GA 蓝图。SkillDefinition.AbilityClass 留空使用内置 CC_ConfiguredAbility；需要自定义演出和流程时再派生 GA，并明确消耗、冷却、命中时机和结束事件。

## 5. 配好初墨和三条开放路线

每份 `CC_FormDefinition` Data Asset：

| 阶段索引 | 意义 | 示例费用 | 需要配置 |
|---|---|---|---|
| 0 | 初级 | 0，初级免费 | 四技能组、属性、可选 Mesh／AnimClass |
| 1 | 中级 | 100 | 同上，Cost 为进入中级费用 |
| 2 | 高级 | 1000 | 同上，Cost 为进入高级费用 |

三阶段都要完整，不能只填当前初级。每份配置的 FormId 唯一且稳定，DisplayName 可随时改。

然后打开 PlayerState 蓝图的 Progression 组件：

- Native Form：DA_Form_InitialInk，不可直接进化。
- Artifact Forms：包含DA_Form_Native自然路线、青铜/陶塑及两条未开放预留，不包含初墨。
- Upgrade Catalog：下一步需要的商品配置。

初墨始终可用，恢复初墨时Switch Form的Form参数留空。自然需白色器物解锁，不是当前默认初始形态；三路线独立记录档位，共用经验。

变身会重算基础属性并保留生命／法力比例。Mesh 留空回退缓存人形；AnimClass 不自动继承上一档。原人形可回退缓存动画，不同骨架则由 Locomotion 的模型记录选择专属 ABP。当前九档均显式填写 Mesh/AnimClass/MeshScale；新增体型仍需自行调整胶囊和相对位置。

## 6. 把场景物体变成器物

### 现有蓝图加组件

1. 打开物体 Actor 蓝图 → Add Component → CC Artifact Component。
2. Form 指向四种器物之一。
3. Enabled 开启，Interaction Distance 先用 250。
4. 静态网格碰撞响应 Visibility；联网 Actor 开启 Replicates。
5. 确认该 Form 已加入玩家的 Artifact Forms。
6. 交互距离默认250厘米，按角色到碰撞组件包围盒最近表面的距离计算；有效碰撞、视线与状态均需满足。

### 使用器物父类

直接拖入 BP_Artifact_01～04，替换 Mesh 即可。它们的 C++ 父类为 CC_FormArtifact，已经有 Artifact 组件。

两种方式可以混用。标签 SpecialArtifact 只作分类；只加标签、没有组件或没有 Form 引用时，不会自动变身。

控制器优先检查摄像机1500厘米Visibility射线有效目标，否则在角色周围450厘米搜索；最终按250厘米表面距离、视线和状态校验。左下提示与E使用同一选目标接口。

## 7. 配置经验商品和怪物

商品创建 `CC_UpgradeDefinition` Data Asset：

1. 填稳定 UpgradeId 和 DisplayName。
2. Type 选最大生命、最大法力、攻击、防御、移速或技能等级。
3. Prices 填每级费用，如 `[25, 50, 100]` 表示最多买三级。
4. 属性商品设 BonusPerLevel；技能等级商品设 SkillId，每次固定加一级。
5. 加入 Progression.UpgradeCatalog，否则服务器拒绝购买。

范围巡逻怪物优先复制 BP_PatrolEnemy，父类 CC_PatrolEnemyCharacter；旧 BP_ProgressionEnemy 保留旧搜索能力路径：

- Initialize／Reset Attributes Effect：默认选择 CC_InitialAttributesEffect，避免空 GE 使角色生命为零。
- Skills.Default Loadout：完整四技能组。
- Experience Reward：由共享档案应用10/40/200/500，首次致死产生奖励粒子，实际接触才入账。
- Experience Particle System：NS_ExperienceOrb；布娃娃默认 0.65 秒后开启，敌人死亡 10 秒后清理。黑色经验包和完整配置见[死亡布娃娃与经验粒子](./死亡布娃娃与经验粒子配置.md)。
- AI Controller Class：AIController。
- Auto Possess AI：Placed in World or Spawned。
- Startup Abilities：巡逻父类不添加 CC_SearchForTarget，避免两套 AI 重复驱动；只有旧搜索路径使用它。
- SearchRange、AcceptanceRadius、攻击延迟按技能距离调整。
- 实现 RotateToTarget；GetTimelineLength 返回转向时长。

关卡放 NavMeshBoundsVolume 覆盖地面并构建导航。当前没有导航时在射程内的远程技能仍可能攻击，但不能据此认定近战寻路已完成。

## 8. 正式输入和 UI 接线

当前 BP_ProgressionController 已接模板移动/视角/空格，以及 J/鼠标左键普攻、1～4 四技能、E 交互和 Tab 菜单。自建控制器时保留对应 InputAction、Input Mapping Context 和动作引用，避免同一物理按键被两条激活路径重复绑定。

正式商城／进化界面从 PlayerState 取得 Progression：

```text
界面初始化 → 绑定 OnChanged、OnPurchaseFinished → 读取余额／当前形态／商品等级
进化按钮 → Evolve()
商品按钮 → Purchase(该按钮持有的 UpgradeDefinition)
原生按钮 → SwitchForm(空)
器物按钮 → SwitchForm(已解锁 Form)
OnChanged → 重读并刷新
OnPurchaseFinished → 根据结果显示提示
```

不要由 UI 自行减少 Experience 或增加属性。画面显示的档位使用 `CurrentTier + 1`，数组索引仍是 0～2。

屏幕经验 UI 使用 Progression.OnChanged；血条等 GAS 属性 UI 使用属性监听。世界空间血条可用 CC_WidgetComponent + CC_AttributeWidget，必须配置匹配的 Attribute／MaxAttribute。

## 9. 先选一种明确的保存流程

### 当前完整单机存档

设置页已接手动保存/读取。新增自动流程时，在初始化完成后调用LoadProgress、保存点调用SaveProgress；目前没有默认自动存读。保存经验、初始ID、路线解锁/档位、当前形态、商品及真实手动四槽；键位另自动写入Controls槽。

### 经验后端框架联调

1. 按 [后端说明](../Backend/README.md) 生成密钥、启动服务。
2. 启动 UE 前设置服务 URL 和 Token 的环境变量。
3. 获取 CC_ExperienceBackendSubsystem，先绑定 OnCompleted，再 LoadCharacterExperience。
4. **读成功且尚未开放战斗奖励**时，将余额传给 RestoreExperienceFromBackend。
5. 保存时提交当前余额；成功回调不能把旧快照反写到正在玩的角色。
6. 网络保存失败遵守 RetryPendingSave 的相同请求重试规则。

本轮后端只存经验；不要将它与本地形态／购买记录混用成已经完整支持跨设备的存档。若读完云端经验后又调用 LoadProgress，本地文件会再次覆盖经验。需要先明确哪一份是权威来源，再编排加载顺序。

## 10. 故障排查顺序

| 现象 | 优先检查 |
|---|---|
| 一进入关卡就断言 | 玩家和敌人的 InitializeAttributesEffect 是否为空 |
| UI 没有新经验／技能 | 关卡是否使用新 GameMode，以及正确的 Pawn／State／Controller |
| 只能用旧三技能 | NativeForm 或 Loadout 是否未配、三档是否都完整 |
| 器物按 E 没反应 | 相机射线、Visibility、组件、Form 白名单、Enabled、距离与视线 |
| 黑色经验包 E 没反应 | 包是否已消费、Repeatable/ReuseDelay、Visibility、距离/视线、玩家是否存活 |
| 击杀未马上加经验 | 当前按粒子接触逐颗入账，先检查领取者 PlayerState 与吸附/接触；不能在死亡蓝图重复 AddExperience |
| 死亡后没有布娃娃 | EnableDeathRagdoll、延迟、Mesh 的 Physics Asset 是否有匹配骨骼的有效碰撞体 |
| 初级可以用但不能进化 | 初墨不可进化；路线检查CanEvolve、三阶段配置、余额及是否封顶 |
| 技能名称变化但打不出效果 | Behavior、法力、槽位冷却、目标阵营和范围 |
| 怪物不动／不循环攻击 | AIController、AutoPossessAI、导航、巡逻父类参数；旧搜索路径才检查 SearchForTarget/EndAttack |
| 发射后看不到弹体 | SkillDefinition.ProjectileNiagara 引用、Niagara 插件、实际渲染模式及特效尺度 |
| 人物没有跳跃或攻击动作 | 当前 Mesh 的 LocomotionLibrary 条目、同骨架 AnimClass、DefaultSlot 与对应动画 |
| 后端 backend_not_configured | UE 进程是否继承了正确环境变量；不是只在另一个终端设置 |
| 后端 load_before_save | 先读取角色版本，不能直接首次保存 |
| 后端 http_409 | 版本过期或请求 ID 内容冲突，不能盲目覆盖 |

各类的详细字段和真实限制见 [C++ 父类索引](./CPP父类配置索引.md)。

铜币与正式18技能接入参见[真实技能与铜币配置](真实技能与铜币配置.md)。当前SaveGame版本3保存铜币，后端仍只经验。

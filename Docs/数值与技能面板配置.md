# 数值、精英与技能面板配置

更新日期：2026-10-24。本文22项表格对应实际战斗模板。新默认技能页18项已经真实装备/执行，并校验流派解锁；保留本页22项模板，完整目录39项。详见[本轮功能配置](真实技能与铜币配置.md)。见[完整说明](完整功能更新与配置说明.md)及[技能美术配置](技能界面美术配置.md)。初始为初墨（75生命／11.25攻击），自然由白色器物解锁。

当前版本以 **生命 100、攻击 15** 为白板。攻击属性现在表示实际攻击点数，不再表示百分比加成。技能先按施放时的攻击力计算强度，再在命中时结算目标防御与护盾，避免重复放大。

## 在编辑器里配置数值

打开 `/Game/HPWH/Balance/DA_CombatBalance`（父类 **CC_CombatBalance**）：

- `BaseHealth / BaseAttack`：白板 100 / 15。
- `Profiles`：每行 `ProfileId` 唯一；`HealthMultiplier / AttackMultiplier` 使用倍率，例如 140% 填 **1.4**。
- `ParentProfileId`：可继承高级行。精英两项自身倍率填 1，`Elite=true`，`EliteMultiplier=1.5`，`EliteScale=1.2`。
- `Mesh`：普通敌人按骨骼网格体自动匹配的入口。共享模型的额外形态不填 Mesh，由实例明确指定 ID。
- `Loadout`：普通怪 `DA_EnemyLoadout`，精英 `DA_EliteLoadout`。

玩家的三个 Form 资产中，每个 `Stages` 已引用此表与对应 `StatProfileId`。表引用存在时生命、攻击以表为准；Stage 原有生命 / 攻击字段仅作未接数值表时的备用值。法力、防御、速度继续在 Stage 中配置，永久购买属性在基础数值之上相加。

怪物父类 **CC_EnemyCharacter** / **CC_PatrolEnemyCharacter**：设置 `CombatBalance`；`StatProfileId` 留空按 Mesh 查找，也可以明确指定。两个可拖入场景的蓝图为 `/Game/HPWH/Blueprints/BP_Bronze_Elite`、`BP_Ceramic_Elite`，已经在测试地图远侧各放置一个。蓝图里保持正常模型大小，运行时自动应用精英 1.2 倍，勿再手工乘一次。`ApplyCombatProfile` 是权威端初始化接口，不应在 Tick 中调用。

## 打开技能与键位面板

运行原测试地图 `/Game/HPWH/Maps/L_FlatTestArena`，按 **Tab**：

1. **技能面板 / 装备技能**：选择槽位 1–4、选择技能、点击装备。下方显示当前四槽、所选技能详情，以及全部 22 个技能的数值简介，滚轮浏览。
2. 已装备技能再次选到另一槽会交换位置，不重复装备。技能或普攻冷却期间不能换装。
3. 手动配置会跨变身、进化保留；“恢复当前形态默认技能”恢复当前档位技能组。所有角色仍有独立的近战普攻。
4. **设置 / 键位与存档**：可改四个技能、普攻、交互键。默认 **1 / 2 / 3 / 4 / J / E**；鼠标左键始终可普攻。WASD、空格、镜头沿用模板，Tab / Esc 返回菜单。
5. 已占用键、模板移动键、菜单键不允许覆盖。键位自动写入 `Saved/SaveGames/SpiritTalesControls.sav`，下次运行恢复。
6. 角色经验、进化、属性购买、手动技能通过设置中的“保存角色进度 / 读取角色进度”保存到 `SpiritTales.sav`。当前为手动读取，避免进入测试地图时自动恢复旧状态。旧版本存档没有技能字段时恢复形态默认技能。

01 取代原先编号 01 的近战模板；近战模板移到 05。形态默认技能组不自动装备 01，需要通过真实装备接口/文字回退页手动装入，或在Loadout指定；当前新美术页可直接真实装备粒子。其他远程模板仍保留原有行为。追踪弹在提供目标时追踪，玩家当前无锁定目标时沿瞄准方向发射。

技能 `PowerMode=AttackMultiplier` 时，`Power=.75` 表示攻击力的 75%，不是填 75；`PowerPerLevel` 同样是每级增加的倍率。`Flat` 则表示固定点数。当前 20 个模板每级增量先设为 0；尤其 01 固定保持 75%。后续可在资产中配置各技能成长。普攻独立资产 `DA_BasicAttack`，倍率 1、零消耗。

`Description` 写用途简介；面板通过 `GetNumericDescription` 直接计算当前攻击下的数值、冷却、消耗、距离、半径、持续时间，连击 / 散射会显示每击 / 每发、持续区域显示间隔，减速显示比例。数值为减伤前：实际伤害 = 技能强度 × 100 / (100 + 防御)，随后优先扣护盾。

一级粒子伤害示例：白板 **11.25**、青铜初级 **15.75**、铜械降神 **84.375**、陶塑精英 **75.9375**。界面保留两位小数，内部使用浮点数。

## 扩充技能库与网络边界

在 `BP_ProgressionPlayerState → Progression → SkillCatalog` 注册可供玩家手动装备的技能资产。服务器只接受目录内资产及 0–3 槽位；有效四槽复制给客户端，不修改共享 DataAsset。手动装备进入 PlayerState，与替换的角色外观分离。每个角色组件的 `BasicAttack` 仍为单独普攻。

粒子使用既有 Niagara `NS_Projectile_01` 与命中特效，通过技能资产 `ProjectileNiagara / ImpactNiagara` 更换。怪物 AI 根据射程和冷却选技能，普通近战保持短射程，精英远程为 1200。

配置脚本 `Scripts/configure_combat_balance.py` 是本次配置的可重建入口，**重跑会重置上述数值与技能模板参数**，日常调参直接改 DataAsset。它不修改 SOURCE 美术资产或动画，测试继续使用原平地地图。

## 原项目按键技能核对与保留

当前 1 / 2 / 3 / 4 是四个槽位，初墨当前四槽默认为 **直拳 / 连拳 / 横扫 / 回复术**；原05/02/04/13仍保留，已全部收进实际SkillCatalog，可用真实接口重新分配（新美术页18项已经可直接真实装备），不会因启用设置而丢失。键位设置通过本地运行时映射副本生效，磁盘里的 IMC 保留默认配置。

另检查了 THAT 的三个旧 GA：GA_Primary 用 FlipFlop 播 MT / MT2 两段拳击，事件后仅绘制调试命中球；GA_Secondary 只有调试打印与结束；GA_Tertiary 是短时改 MaxWalkSpeed 的调试流程，原图有调试条件门控与速度恢复隐患。旧模板原键位为鼠标左 / 右 / T，并没有第四个完整 GA。

可复用机制整理为 **21 交替拳击**、**22 短时疾跑**。它们使用统一执行器、当前骨骼对应动画、服务器伤害 / 冷却 / 消耗与 GAS 到期恢复。21 补齐实际伤害；22 默认由旧的调试速度 10000 改为可配置的 +500、持续 1 秒，基础 500 时达到 1000，后续在资产里改 Power / Duration。旧 Secondary 保留源资产，尚无玩法效果，未冒充已完成技能。

21 的 `AlternateAttackPose=true`：服务器交替选择 Jab / CrossJab，并把选中的姿势通过 multicast 发送客户端，不修改共享技能资产。22 使用已有 SpeedBuff 模板，和 18 的区别是短时强加速。

`Scripts/audit_legacy_abilities.py` 是只读旧蓝图检查入口，输出在 Saved/LegacyAbilityAudit.json 和三个 GraphAudit.txt；`Scripts/configure_legacy_skills.py` 重建额外两项并注册 22 项目录。重跑基础数值配置脚本后，再运行这个补充脚本恢复两项注册。

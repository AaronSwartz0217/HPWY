# 敌人近战与相机避障配置

敌人旧组包含投射物与范围爆发。本次保留玩家技能库，改用独立的四个近战技能资产：`/Game/HPWH/Skills/Enemies/DA_Enemy_Melee_01`～`04`，由 `/Game/HPWH/Loadouts/DA_EnemyLoadout` 引用。场景十个敌人及三个敌人蓝图默认技能组均同步。

四槽为直拳、连拳、横扫、重拳，使用 Jab/CrossJab/Uppercut 姿势；距离190cm，免费施放，按各槽冷却轮换。巡逻怪物追到150cm左右交战。施法和投射物特效留空，命中时只出现小火花。死亡产生的10颗经验光球保持原逻辑。

C++ 原来已有 CameraBoom 弹簧臂，本次修复继承蓝图覆盖及挂接、支点和碰撞配置。默认臂长600cm，支点高65cm，肩部偏移(0,45,15)，Camera通道检测半径16cm。贴墙自动缩回，镜头距人物模型中心小于100cm时仅对本人隐藏网格，退开后恢复显示。没有强制碰撞后的最短距离，避免将镜头推到墙后。

新场景的墙、地形和大型障碍物需要阻挡Camera通道。人物与尸体忽略该通道，减少靠近怪物时镜头跳动。配置父类见 [玩家类](CPPClasses/ACC_PlayerCharacter.md)。

维护脚本 `Scripts/configure_enemy_melee_camera.py` 会重写上述敌人技能及地图配置，后续手工调参后不要无意重跑。场景验证命令 `CC.MeleeCameraSmokeTest` 检查四槽近战、实际扣血、墙前缩回、防止进入墙内、近距离隐藏及恢复，结果写 `Saved/MeleeCameraSmoke.json`；只在独立测试游戏进程运行，会自动退出。

本轮Win64 Development编译通过，场景物理/逻辑验证全部通过（NullRHI模式）：四槽近战、扣血、零投射物、墙体收缩、墙外镜头、近景隐藏和恢复。原有三个核心自动化测试均通过且零警告。本轮未对所有复杂美术障碍物逐一验收；没有Camera碰撞的资源仍需补碰撞。

# 斑斓墨水人外观

墨人本体保持黑色，彩色效果只通过 Overlay Material 叠加描边。原始流光资源迁移到 `/Game/场景资源特效/流光特效`，其中彩色 MatCap 保留为素材，不用于当前角色身体。

游戏使用 `/Game/HPWH/Effects/ChromaticInk`：

| 资产 | 用途 |
| --- | --- |
| M_InkBlack | 初墨独立网格体的黑色材质，无彩色自发光 |
| M_InkOutline | 不发光的背面壳彩色描边：沿法线扩张，裁掉正面；保留向上游走的轮廓扰动 |
| MI_InkOutline_Clean | 不扭曲描边，DistortionStrength=0 |
| MI_InkOutline_Burning | 扭曲描边，DistortionStrength=1；游戏默认使用 |
| M_ChromaticHealth | 横向流动彩虹渐变，作为原血条 FillImage，仍按实际生命比例填充 |

`BP_ProgressionCharacter` 的 ChromaticOutlineMaterial 选择描边实例。普通版只需换为 MI_InkOutline_Clean。本体来自 SK_InitialInk_Template 自己的黑色材质槽，Q 不替换身体材质。旧 MI_InkMatCap 两个实例现均引用黑色材质，保留以兼容引用；游戏不使用它们切换身体颜色。

描边使用 Default Lit，彩色算法接入 Base Color，自发光通道固定为0；普通、扭曲两版均不产生自发光光晕。黑色主体和彩虹血条保留。可调整描边参数：OutlineWidth（厘米）、FlameHeight、OutlineColorStrength、OutlineRoughness、OutlineSpecular、DistortionStrength；黑色材质可调整 InkBlack、Roughness、Specular。

## 触发与恢复

- 集齐前：Q 开启/关闭临时测试，同时预览彩虹血条。临时测试不写入存档。
- 实际取得自然 Native、青铜 Artifact_01、陶塑 Artifact_02 三条路线后：自动开启常驻外观和彩虹血条，只需要元素信物入包，不要求进化或装备。
- 集齐后：Q 关闭/重新开启描边，黑色本体保持。彩虹血条继续显示，集齐状态不受影响。
- 关闭时恢复此前的 Overlay Material；切换器物模型后重新挂接描边，保持各形态自己的身体材质。
- 描边关闭偏好随已有进度快照保存及跨地图恢复；旧存档新增字段默认 false，集齐三力时默认显示外观。
- Q 在菜单、传送锁定及死亡状态下不触发；Q 保留为外观按键，不能重复绑定战技。

只改变渲染和血条颜色，不修改当前形态、技能、生命、攻击、移动或费用。多人只额外同步外观状态，不向其他客户端公开完整元素背包。

## 生成与检查

`Scripts/setup_chromatic_ink.py` 在 Unreal Python 中创建两套材质实例。`Scripts/capture_chromatic_ink.py` 生成专用预览地图 `L_ChromaticInkPreview` 和实际 Unreal 渲染图。正常玩法地图不增加展示角色。

自动测试：`CrashCourse.Progression.ChromaticInk`。游戏控制台烟雾检查：`CC.ChromaticInkSmoke`，结果在 `Saved/ChromaticInkSmoke.json`；烟雾检查使用开发测试状态并关闭自动存档。
